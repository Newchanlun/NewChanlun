#### 1.5.2 原典的直接证据

- MACD 没有特殊性：【课间 100:96】「并不是说MACD有什么特殊的地方」。
- 动力学不是微积分与级数：【正文 104:16】「用各种微积分或各种级数等等无聊算法就是了」，这是作者批评的看法。
- 一切能量动力形态几何化：【正文 104:26】「一切都是几何结构说了算，一切的能量动力形态，都变几何化」。
- 晚期保证收窄：【正文 098:16】「理论只能保证其回拉原来的中枢」，以及【课间 105:522】「而在本ID理论的确保性上说，只能说是2990点」。
- 区分"可能的背驰"与未成立（防混用依据，不宣称原典已构成定义循环）：【正文 079:52】「如果合力最终的结果把可能的背驰给破坏了，就证明这地方没出现背驰」。
- 2008-07-01 的有条件预测判例记录：【课间 105:518】「一旦这次的下跌最终完成，针对6124点下来的最低反弹理论确保幅度是必然回到2990点之上」。105:516 与 105:526 同时保留了第三中枢可能；"实际走势未回 2990 点之上并形成第三中枢"出自同行编者注，不能单独证明前件成立而回拉失败。它作为有条件预测判例记录进 `Chan/Audit/Cases`，不作回拉保证硬反例。

#### 1.5.3 M16、M17、M19a 的要点

- **M16 把力度做成三分量接口。** 窗口由规范分解给出，是纯形态学。势函数是时间轴上的因果量（各自声明平移变换律，平移不变性统一挂在最终读数上）。读法是端点差或正变差，外加端点约定。原典的两个代理正好差一阶：均线面积是位移型，MACD 柱面积是速度增量型。结构内蕴族是第三族。
- **结构内蕴力度的主线默认值没有定。** 候选包括"从静止起算的均速"与第二份 Astra 审计提出的独立对照候选（两者在分离路径上排序相反，后者定义式不进盲写引文包，留对撞阶段与 FM-42 裁定）。默认值由 FM-60 的判例回归加对撞与独审来定，不靠讨论。【推断】
- **M17 的背驰谓词只依赖历史。** 进行中的 c 段取"起点已确认、终点为当下"的窗。DivConfirmed 单独命名。两可延拓定理给出无条件边界：含两个已确认同级中枢且现价在后一个之上的历史，既能延拓回中枢，也能延拓出下一个中枢。
- **M19a 只保留一条待检的动力学命题。** 它是"Div 之后回到最后中枢"。登记状态是无条件不可证，另有条件定理、边界反例和经验回归。定理名不叫"背驰必转折"。

#### 1.5.4 M19b：第 33 课中枢回拉模型

原文只有三处关键句。【正文 033:24】「把这些看成不同的星球，在当下位置上的星球对当下位置产生向上的力，当下位置下的产生向下的力」。【正文 033:26】「而中枢有这样的特性，就是对无论向上或向下离开的，都有相同的回拉作用，既然向上离开比向下离开要弱，而向下离开都能拉回中枢，那向上的离开当然也能拉回中枢里」。【正文 033:30】「因为中枢B对这两段的回拉力度是一样的」。作者还说力度是当下的量：【答疑 041:311】「力度是当下的」。

这段论证涉及四条前提，归属与边界逐条核实如下：

| 前提 | 来源与边界 |
|---|---|
| 回拉作用对两侧相同 | 【原文 033:26】原文明说 |
| 把进入中枢的那一段 b 反向读作向下离开中枢 B | 【原文 033:26】同行前半已明文提出（"那么b可以看成是向下离开中枢B"；【原文 033:24】亦先说"虽然A其实是后出现的"），非本文首次补出；D1 中附加"b 自静止落入"等物理初始条件才是新增建模前提 |
| 回拉作用不随时间减弱 | 【原文 033:30】仅就该例"这两段"说回拉力度一样；将其推广为任意时刻不随时间减弱是登记者另加的模型律，且非推出个案回拉的必要条件 |
| 回拉结果关于离开力度单调 | 【推断】形式化必须补出的隐含前提。若缺失此条，令 R(2)=真、R(1)=假且两侧与各时刻同用 R，前三条皆成立而"力度更弱必回拉"仍为假 |

研究问题只有一个：在以最后中枢为锚的局部模型里，"力度比较推出回拉"最少需要哪些假设，每条假设去掉后的逃逸反例是什么。产出是边界图，不是一条正面定理。

分五级推进，每级先在小整数格上穷举，再写陈述。

| 级 | 内容 | 目标陈述 | 状态 |
|---|---|---|---|
| D0 | 字面读法审计 | 项目 D0 加强模型：把"回拉关系对力度单调、对两侧对称、对时间平移不变"写成三条。三条不是 033:26 的直译：两侧对称出自 033:26，不随时间减弱是从 033:30 的个案推广，单调性是形式化补出的前提（见上表归属）。在这三条下结论三行可证。但假设里出现了结论谓词"回拉"，过不了门禁 14。它进 `Chan/Audit/Math`，记为"原典论证等于假设了结论的单调闭包" | 【推断】 |
| D1 | 单中枢势阱 | 位置的二阶递推，回拉只依赖位置、两侧对称、不随时间变、作用范围有限，滑行期间没有外加推力。b 自静止落入。若 c 离开中枢边界时的增量不大于 b 到达边界时的增量，则 c 的最大偏离不超过 b 的起点偏离加一步余量，并在有界步数内回到中枢区间 | 【推断】常力情形手算成立，带一步离散余量 |

### 3.3 每个蓝图节点的八步

前五步完成之前不写证明。

1. **立项。** 主控写蓝图节点：非形式陈述、出处、类别、依赖。出处只取自已复核台账。
2. **盲写双形式化。** 甲乙双方各自只看引文包写出 Lean 定义，见 3.4。
3. **对撞。** 在 Lean 里证明两份定义等价，或用小模型穷举找出分离路径。
4. **反例先行。** 非作者方对拟证定理搜反例，见 3.5。
5. **独审封闸。** 见 3.6。
6. **锁定。** 声明评审 PR 更新锁文件并合入。
7. **证明。** 证明工位只改 `Chan/Thm` 与 `Chan/Proofs`。证不出不许改语句，交"不可证报告"。
8. **证明后审计。** 非作者方确认语句没有漂移、没有禁用构造、抽象测试仍然通过。

### 3.4 盲写对撞与防泄题协议

**输入只有引文包。** 主控为每一批出一个引文包，内容四项：节点的非形式陈述；逐字引文与课行号；相关的清单 B 修复裁定与七项顶层裁定；接口约束页。接口约束页只写命名空间、文件名、要产出的公开定义名和一句话职责、载体类型、`module` 规范。引文包里没有任何 Lean 签名。它提交到 `pack/<批>` 分支并记下 SHA。

**禁读清单。** 对方的分支与线程。旧 `formal/` 与 `.chanlun/definitions/` 里的同名定义。前者是冻结的旧库，后者不是本包的锚点。

**物理隔离五条。**

1. 甲方在 SafeCode，乙方在 Mac。两台机器上的盲写分支在双方都报完成之前不推送到 origin。
2. 主控给乙方的简报只由固定模板加引文包路径生成。简报原文贴进票里备查。
3. 主控不把甲方的签名、文件内容、编译报错转给乙方，反过来也一样。
4. 双方报完成后，主控先把两边的 head SHA 写进票里，这一步叫封存。封存之后才推送两条分支，这一步叫揭示。
5. 任何一方在封存之后改稿，改动算新一轮，原稿保留。

盲写简报的固定模板如下。主控只填尖括号里的四项，不加别的内容。

```text
目标：为声明包 <批号> 写出 Lean 定义草稿，供对撞使用。本任务只写定义，不写定理证明。
输入：只读分支 pack/<批号> 在提交 <SHA> 上的引文包。不读其他分支，不读其他线程，不读 formal/ 与 .chanlun/definitions/。
产出：在分支 blind/<批号>-<甲方写 f，乙方写 a> 上提交 formal_math/Chan/Defs 下接口约束页列出的文件。每个定义的文档串带引文包里的课行号与逐字引文。
验收：lake build --wfail 退出码 0。每个定义可判定或给出可判定实例。不出现禁用构造。
不要推送分支。完成后只回报 head SHA 与构建退出码。
固定约束：手册 3.9 的十四条，原样附后。
```

**对撞由非作者执行。** 对撞工位是 Sol。对每一对定义，结果三选一。

| 结果 | 含义 | 去向 |
|---|---|---|
| 等价 | 在 Lean 里证出两份定义逐点等价 | 主控按"结构递归、可判定、垃圾值暴露点少"取一份进 Defs，另一份连同等价证明留在 `Chan/Proofs` |
| 分离 | 穷举器在有界长度内找到一条判定不同的最小路径 | 进下面的分离裁定 |
| 未定 | 没有等价证明，界内也没有分离路径 | 升到 Astra `xhigh` 或 Fable 证等价，同时加大穷举界 |

**分离裁定按证据分三种。**

- 一方与某条逐字引文或作者判例相反。这一方有错，改掉。分离路径进 `ChanTest` 作回归。
- 原文没有说，或原文自相矛盾。这是一条真的 B 类歧义。两份都做成显式参数的实例，分离路径进 `Chan/Audit/Separation`，用 `decide` 证出"甲成立而乙不成立"，并在 `formalization.yaml` 记一条。
- 双方都错。退回第 1 步。

默认值之争由判例回归定。判例定不了时请第三家族审。Mac 上有 Gemini 4 Neon，它的额度据记录约在 11 月 26 日恢复【实测·前序】。

### 3.5 反例先行

### 3.6 异构独审、封闸与熔断

- **独审清单。** 出处逐字与作者归属。量词与严格性。等号口径。垃圾值。前提可满足。抽象测试。结论形状。`module` 合规。力度四参数。假设五项。
- **结论二值。** PASS 或 BLOCK，绑定 head 与语句哈希。BLOCK 要指到清单条目，并尽量附可机检的材料：反例、引文位置、失败的门禁。
- **档位。** 普通独审用 `xhigh`。三处封闸用 `max`：改锁的声明评审 PR，#2296 蓝图冻结，FM-71 终审。

- **两次 BLOCK 熔断。** 同一道闸两次 BLOCK 就停止修补。主控写下两次修补共用的前提，直接检验这个前提，然后退回第 1 步。票进 held，评论写"裁决暂停"并附 BLOCK 表。不改判，不换审查者刷结果。
- **没有合格审查者时闸门保持关闭。** GPT 额度不可用时，不用 Claude 家族顶替异家族独审。不依赖独审的工作照常进行。
- **审查输出解析失败。** 不计 PASS，也不计 BLOCK，重跑一次。

### 3.8 批量证明与疑难升级

Lean 证明的对错能自动验证，所以先低档全跑，只把失败的升档。

| 级 | 执行者 | 范围 |
|---|---|---|
| L0 | Sol `low` 或 `medium` | 一个节点的全部引理跑一遍 |
| L1 | Sol `high` | 只重跑失败的 |
| L2 | Astra `xhigh` | 只重跑仍失败的 |
| L3 | Fable `high`，SafeCode 单槽串行 | 只重跑仍失败的 |
| L4 | 证明工位交"不可证报告" | 主控三选一处置 |

每一级至多试两次。L4 的三种处置：语句为假，反例进 Audit 或走声明评审 PR 改定义；缺引理，开新节点；确属难题，标为研究项，不阻塞兄弟节点。

"不可证报告"的模板：目标语句的哈希，卡住的子目标，已经试过的策略，反例候选与它的 `decide` 结果，建议。

### 3.9 给 GPT 工位的固定约束

每份简报原样带上这十四条。

1. 每个 `.lean` 文件第一条命令是 `module`。公开签名用到的模块用 `public import`，其余用 `import`。定义放进 `@[expose] public section`，定理放进 `public section`。

3. Mathlib 名称先在本机 `#check` 再用。`List.Chain'` 已不存在，现名 `List.IsChain`。
4. 禁用 `axiom`、`sorry`、`admit`、`native_decide`、`unsafe`、`extern`、`implemented_by`、`partial`、局部 `set_option linter`。`#eval` 只许出现在 `ChanExplore`。
5. 不改 `Chan/Defs`、`Chan/Hypotheses`、`ChanChallenge`、`statement-lock.json`、`lakefile.toml`、`lake-manifest.json`、`lean-toolchain`。只有 `decl/` 与 `infra/` 分支的简报会明文解除其中某一项。
6. 证不出不改语句。交"不可证报告"。
7. 每条 shell 命令保持短、单一用途。多行脚本先用文件编辑工具写成文件再运行。命令里不写 `rm`、`rmdir`、`trap`，不用 heredoc。

9. Mathlib 只用 `lake exe cache get` 取预编译缓存。看到 Lake 开始从源码编译 Mathlib 就立刻中止并报告。
10. 用 `lake build --wfail <目标模块>` 循环。交卷前跑一次全包 `lake build --wfail` 和本机能跑的门禁脚本。
11. 文档串里的课行号与引文只从引文包复制，不改写，不引编者注。
12. 盲写工位不读对方分支，不读对方线程，不读禁读清单里的文件。
13. 后台任务没有结束之前不结束回合。在同一回合前台等到它退出并拿到退出码。
14. 只推分支或开 PR，不合入。最后一行写 `RESULT: 分支，head SHA，构建命令与退出码，门禁结果，未解决项`。
