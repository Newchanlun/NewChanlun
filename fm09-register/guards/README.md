## G2 合并行与跨帖行

**触发。** 原行满足其一即为合并行：两个及以上时间戳；尾戳之外的连续四个以上星号；行中部（不在行首行尾）五个以上等号或短横。

**检查对象。** 台账全部 1,604 条落在合并行上的引文；四份文档里所有硬引文；四份文档里裸引的合并行课行。

**判定。** 按下节的帖切分器把该课答疑区切成段。引文（按“…”切片后每一片）必须整体落在单一段内，且该段按规则 R-A 判为作者答语段；否则该课行必须在禁引表里，不在就红。文档裸引的合并行若台账在该行没有引文可定位，或该行有不合格的台账引文，也必须在禁引表里。

**分类（只作说明，不影响判红）。** 行内带时间戳的记号（帖头时间、尾戳）分属两个及以上帖，判“多帖合并行”；否则判“单帖行”，包括一行一问一答和单帖多轮续行，允许尾挂下一帖无时间的名头残片。真实行测试（`selftest.py`）：040:34、047:116、052:470 判单帖行且引文合格；040:36、048:84 判多帖合并行。

本轮台账落在合并行上的引文 17 条：7 条在禁引表（040:36 三条、040:52 两条、048:80、048:84），其余 10 条都落在单一答语段内。另有 11 个台账无条目的合并行被文档裸引，已登记为 `excluded_lines_r3`。

## 帖切分器（G2、G3 共用）

**记号。**

| 记号 | 形态 |
|---|---|
| 尾戳 CS | `(YYYY-MM-DD hh:mm:ss)` 及其后的星号或短横，收束一帖 |
| 作者帖头 AH | `缠中说禅` 后接冒号或时间戳，或独占一行；近名 `缠中说缠` 同样识别并标近名 |
| 提问者名头 QN | `[匿名] 名`（含缺左方括号的 `匿名] 名`）、`名 删除此人所有评论`、`文章提交者：名` |
| 帖头时间 TSX | 不在括号里的时间戳 |
| 分隔 SEP | 两个以上 `=` 或 `＝`；三个以上 `-`；行首或问句收尾字符后的 `--`；三个以上全角破折号；两个以上 `－`；行首、问句收尾字符后或行末的单个 `=` |
| 跨帖星号 PSEP | 不跟在尾戳后的四个以上星号 |

**成帖规则。** AH 在行首另起一帖（行中出现、且当前帖已有提问者而尚无分隔时，视为问句里转引的作者帖头）；QN 在作者帖的问句区内追加提问者，否则另起提问帖；TSX 紧跟 AH 名头为作者时间、紧跟 QN 名头为提问者时间，在尚无分隔的帖内追加提问者，否则另起提问帖；CS 收束当前帖；PSEP 结束当前帖。尾戳之后没有帖头的文字另起无头帖。

**规则 R-A（作者答语段）。** ① 无帖头无提问者的帖，有尾戳收束即答语；② 作者帖头而无提问者（作者自发帖、解盘、图例）全帖为答语；③ 其余段须紧随分隔符，且满足其一：其后不紧跟分隔符；或从帖尾倒数其后帖内分隔符个数为偶数（帖总以作者答语收尾）。以问号或“吗”“呢”收尾且其后紧跟分隔符的段一律是问句。

**已知局限。** 多轮帖里夹在两个分隔符之间、又不以问号收尾的问句段，可能被奇偶判成答语；网友在问句里先抄课文、再用分隔符接问题的版式，会让正向奇偶失效（R-A 用倒序奇偶兜底）。这类漏判只会放过问句，不会把真答语判红，所以 G2 的合格结论仍须与台账的人工归属一起读。
