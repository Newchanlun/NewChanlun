### 0.1 引文用法

### 0.2 符号

- 段写作 `(方向, [低, 高])`，下标从 0 起；未另说明时第 0 段向上，方向逐段交替。
- `核(s)`：第 `s`、`s+1`、`s+2` 三段值域的公共交 `[ZD, ZG]`；非空即「在 `s` 成核」。
- `延伸长(s)`：3 加上其后连续与 `核(s)` 闭重叠的段数。
- `九段升级(s)`：`延伸长(s) ≥ 9`，且 `[s,s+3)`、`[s+3,s+6)`、`[s+6,s+9)` 三组的凸包有公共点（`W11` 既定的三凸包校验）。
- `首核(i)`：从 `i` 起第一个能成核的下标（`W11` 既定的前导搜索）。
- 「折线」指 `Zigzag` 子类型（相邻段共用端点且端点为极值），「交替序列」指一般 `AltSeq`（允许跳空）。

## 一、M6 高阶方向交替律（轴 `U-1`）

### 1.1 裁定

1. **高阶层载体采用宽松 `List (Seg P)`**。深度 0 仍是 `AltSeq P`；深度 ≥ 1 的粗化序列不带方向交替不变式，只带两条不变式：每段值域等于所辖块的完整凸包，相邻段的来源跨度首尾相接且保序。
2. **不设归并段，不设虚拟连接段，也不把「块长为奇数」加成接口律**。三者各有显式反例（1.3 节）。
3. **`Seg.dir` 在深度 ≥ 1 的含义定为「起笔方向」**：等于该块底层第一段的方向，即 `CoarseDirPolicy` 的首段档。另由切点表导出「收笔方向」（该块底层最后一段的方向），不入 `Seg` 字段。
4. **严格交替的正确高阶替代是「衔接交替律」**：任意相邻两上级块，前块收笔方向与后块起笔方向相反。它在所有深度上无条件成立，是定理而不是类型约束。

硬证据：`[018:24]`、`[020:48]`、`[020:54]`（中枢区间只用三段高低点，不用方向）；`[017:56]`、`[038:26]`（走势类型的连接不要求方向交替，同级别分解明文允许盘整接盘整）；`[018:40]`（三段重叠后盘整随时可完成，不限定段数奇偶）；`[053:20]`（次级别整体当作本级一段）。

背景旁证：`[二级旁证 018:36]`（走势类型至少三段次级别，同样只讲段数下限）。

### 1.2 构造性论证

**引理 1（奇偶律）。** 设底层为交替序列，切点 `c_0 < c_1 < … < c_m`，块长 `n_k = c_{k+1} − c_k`。首段档下，第 `k` 块与第 `k+1` 块同向当且仅当 `n_k` 为偶数。证：第 `k+1` 块的首段是第 `k` 块首段之后的第 `n_k` 段，底层逐段反向。

**引理 2（任何保序不变的方向档都救不了偶数块）。** 取 9 段 `s0..s3 = [10,20]`，`s4..s7 = [30,40]`，`s8 = [50,60]`，切点 `[0, 4, 8]`。两块在 A2 语义下都合法：块 0 在 0 成核，`s3` 触核，`s4` 脱核；块 1 在 4 成核，`s7` 触核，`s8` 脱核。块 1 的内容是块 0 经严格保序映射 `x ↦ x + 20` 的像，且两块底层方向序列都是「上下上下」。凡只看块内容、且满足接口律第 3 条（保序不变）的方向档，必给两块同一方向。所以只要块语言接受非末尾偶数块，就不存在使上级序列恒交替的合法方向档。

**引理 3（衔接交替律）。** 深度 1 上，前块最后一段与后块第一段是底层相邻段，方向相反。深度 `d+1` 的块由深度 `d` 的段组成，起笔方向取首个下级段的起笔方向，收笔方向取末个下级段的收笔方向，归纳即得各深度成立。两个方向都是「底层在某个原始切点左右两段的方向」，因此完全由底层与原始切点表决定。

**推论。** 上级序列严格交替，当且仅当每个非末块的起笔方向等于收笔方向，当且仅当它所含底层段数为奇数。奇数块是可判定的派生性质，可以作为定理前提使用，但不能进入塔的可构造性条件：`W9` 已裁定必须接受 `[057:42]` 的 10 段块，`W10` 已裁定必须解除按首段方向交替的拦截，二者都排除了奇偶接口律。

### 1.3 边界反例

1. **强制交替不可行**：引理 2 的 9 段例，以及 `W10a` 的 8 段例（切点 `[0, 4, 7]`，两块起笔都向上）。
2. **虚拟连接段不可行**：8 段 `s0..s2 = [10,20]`，`s3 = [10,30]`，`s4..s6 = [22,40]`，`s7 = [50,60]`。A2 下切点 `[0, 4, 7]`，两块凸包 `E = [10,30]`、`F = [22,40]`，起笔都向上。若在其间插入虚拟反向段 `V = [25,25]`，则 `E`、`V`、`F` 三者有公共点 25，按 M5 闭重叠口径即成核，凭空造出一个只含两个真实次级别走势的上级中枢，违背 `[018:24]` 要求的三个完成的次级别走势。此外虚拟段没有来源跨度，上级切点表会出现重复原始下标，破坏严格递增。
3. **归并不可行**：归并同向相邻块等于删去一个切点。按 `#2318` 结论二，切点表不同就是另一份分解。引理 2 的例子归并后得到含两个波动区间严格分离的中枢的 8 段块，已不属于单中枢块语言；而 `[038:26]` 的盘整接盘整正是同级别分解必须保留的连接。
4. **净走势方向档不是全函数**：块 `(上,[10,20]), (下,[10,20]), (上,[10,20])` 没有净方向；`Seg` 在 `AltSeq` 上不带端点价，净方向在核心载体上无从计算；`Dir` 是二值类型，「无向盘整态」放不进去。它即使有定义也不交替，`[017:56]` 允许上涨接盘整再接上涨。

### 1.4 对 M5 上级中枢的精确影响

1. **成核条件**：上级中枢仍是连续三个上级段凸包值域的闭区间公共交非空，不读方向，不需要方向交替作前提。因此合稿的 `Center` 不能把「覆盖段方向交替」作为结构字段带到深度 ≥ 1（对撞蓝图 5.2 第 8 行沿用了乙方的 `alternating` 字段）。该字段在深度 0 由 `AltSeq` 自动成立，移除它不改变 `W1` 至 `W20` 任何见证的真值，因为全部见证都是交替序列。
2. **重迭区间**：核仍是前三个上级段值域之交，波动区间仍是覆盖段值域的凸包，延伸仍是单段与核闭重叠。按 `#2318` 结论三，上级段值域含块内前导段与延伸段，不只是下级核。
3. **第三类事件**：修复后的公式（`W8`）里，离开段的方向合取项在深度 0 是冗余的，因为回试段向下已蕴含前一段向上。到深度 ≥ 1，偶数离开块的起笔方向与收笔方向相反，这一合取项会把真事件判假。统一写法是只保留「`ZG <` 离开段高点」「回试段起笔向下」「`ZG <` 回试段低点」三项（向下对称）。在交替序列上它与 `W8` 既定公式逐点同真值，在上级层由衔接交替律保证语义正确。
4. **`#2318` 切点表判同**：方向档是规则级参数，起笔与收笔方向都是底层与原始切点表的函数，所以切点表相等蕴含各级粗化序列逐段相等（含方向），合法性由切点表决定，证书不入判同。宽松载体还使粗化成为全函数，任何合法切点表都能成塔，`W10a` 可构造。

### 1.5 对 M9 走势类型交替性的精确影响

1. M9 不存在、也不得推导任何交替律。`classifyTrend` 只看同级中枢个数与相邻波动区间是否严格分离（`[017:44]`、`[017:46]`），本来就不读方向，定义不变。
2. 相邻完成块可以同类型、同起笔方向。走势的方向只由 `TrendKind` 给出；盘整没有方向，M9 不得拿上级段的 `Seg.dir` 当走势方向用。
3. `TrendFormingProspect` 沿用 `W14` 既定公式；在深度 ≥ 1 其中的方向合取项按起笔方向读，几何推进条件不变。
4. M15 在深度 ≥ 1 取方向时，锚在段起点的角色（回试、反弹）读起笔方向，锚在段终点的角色（一类点所在的离开段）读收笔方向。

### 1.6 `CoarseDirPolicy` 是否修改

- **参数化层级不改**：维持规则级或类型级参数，不回到逐塔自由字段。
- **默认值不改**：默认为首段档。
- **可选档要收窄**：能写进 `Seg.dir` 的只有首段档。末段档改为由切点表导出的访问函数。净极值方向档与无向盘整态不得作为 `Seg.dir` 的取值，需要时另立返回 `Option Dir` 的派生标注。
- **新增一条待证定理名**：衔接交替律，以及「严格交替当且仅当非末块含奇数个底层段」。

## 二、M6 `IsCanonical`：局部贪心与全局结合律回溯（对撞表第 62 项）

### 2.1 裁定

1. **两者在同一个单层切分谓词里不可兼得。** 「局部确定」指某级的块终点只由本级段序列决定，并且至迟在下一个同级结构完成时可以确认。「跨级结合律优先」指 `[099:26]` 的要求推到各级：只要某份合法分解能确立更高级别的中枢，就必须选它。2.3 节给出 14 段显式反例，并说明反例可以把所需展望拉到任意长。
2. **单层之内的优先不在此列。** 同一级上的九段升级优先，决策视界有界：一个切点是否被某个九段延伸跨过，至迟在该切点之后第 8 段就已确定。这类优先可以写进规则的 `rank` 与 `confirmed`，仍然是局部确定的，与 `#2318` 的唯一性前提相容。
3. **分层裁定**：`IsCanonical` 定为局部版；跨级结合律重组另立为不带确认语义的全局选择器，只产出「重组视图」。职责边界见 2.4 节。

硬证据：`[038:18]`、`[101:52]`、`[102:38]`（分解必须唯一）；`[099:22]`、`[099:26]`（结合律重组会拆开前段，划分须先保证高级别中枢确立）；`[057:40]`（同一走势可有多份合乎结合律的分解）；`[099:16]`（未完成走势本来测不准）；`[020:40]`（更大级别中枢产生前，本级走势类型延续）；`[018:40]`（三段重叠后随时可以完成）。

### 2.2 数学分析

设合法块语言为：`[i, j)` 合法，当且仅当 `s = 首核(i)` 存在且 `3 ≤ j − s ≤ min(延伸长(s), 9)`。这是 `[018:40]` 的「随时完成」，也是 `W10b` 中乙方承认的「合法但不占优」块。占优终点取最大延伸（A2，依据 `[020:40]`、`[020:56]`）。于是同一起点可有多个合法终点，但占优终点唯一，局部规范分解唯一；这与 `#2318` 「3+5 与 5+3 并存、另需起点定终点」的实测一致。

记 `LG(x)` 为逐步取占优终点得到的切点表。记 `GA(x)` 为满足跨级优先的切点表：在全体合法切点表中，优先取使上一级能成核者，其余情形与 `LG` 相同。

**命题 A（静态不相等）。** 存在有限序列 `x` 使 `LG(x) ≠ GA(x)`。

**命题 B（与确认稳定律冲突）。** 存在前缀 `p` 与它的两条延拓 `x1`、`x2`：`LG` 在 `p` 上已确认的块，被 `GA(x1)` 改写。因此若把 `IsCanonical` 取为 `GA`，接口律第 5 条（已确认部分前缀稳定）不成立；若坚持第 5 条，则 `GA` 的任何块都不能在有界展望内确认。

**命题 C（单层有界）。** 设某切点 `j` 被一个九段延伸跨过，该延伸起于 `p < j`。它是否成立由第 `p+8` 段决定，而 `p + 8 ≤ j + 7`。所以单层升级优先至多需要 8 段展望。

### 2.3 显式有限反例

共同前缀 `p`（10 段，下标 0 至 9）：

- `s0..s4 = [100,200]`
- `s5..s7 = [220,300]`
- `s8 = [310,315]`，`s9 = [320,325]`

延拓一 `x1 = p ++ [[150,400], [150,400], [150,400], [500,510]]`；延拓二 `x2 = p ++ [[330,400], [330,400], [330,400], [500,510]]`。

逐项核对：

1. 起点 0：在 0 成核，核 `[100,200]`，`s3`、`s4` 触核，`s5` 脱核，延伸长 5。合法终点为 3、4、5，占优终点 5。
2. 起点 3：`首核(3) = 5`，核 `[220,300]`，`s8` 脱核，所以 `[3, 8)` 合法（前导 `s3`、`s4` 加三段核）。起点 5：`[5, 8)` 合法。
3. 起点 8 在 `x1` 中：`首核(8) = 9`，核 `[320,325]`，`s12` 触核，`s13` 脱核，块 `[8, 13)`，凸包 `[150,400]`。在 `x2` 中：`首核(8) = 10`，核 `[330,400]`，`s13` 脱核，块 `[8, 13)`，凸包 `[310,400]`。
4. `LG(p) = [0, 5, 8]`，`LG(x1) = LG(x2) = [0, 5, 8, 13]`。
5. 切点表 `T = [0, 3, 8, 13]` 在 `x1` 上的三个上级段值域为 `[100,200]`、`[100,300]`、`[150,400]`，公共交 `[150,200]`，上一级成核。切点表 `T' = [0, 5, 8, 13]` 的三个上级段值域为 `[100,200]`、`[220,300]`、`[150,400]`，前两者不交，上一级不成核。
6. 在 `x2` 上，`T` 给出 `[100,200]`、`[100,300]`、`[310,400]`，`T'` 给出 `[100,200]`、`[220,300]`、`[310,400]`，两者都不成核。

结论：

- 命题 A：`GA(x1) = T ≠ T' = LG(x1)`。
- 命题 B：在前缀 `p` 上，块 `[0, 5)` 的脱核段 `s5` 已出现，后一块 `[5, 8)` 也已完成，按局部确定的要求此时 `[0, 5)` 已确认。`GA(x1)` 要求切点 3 而不是 5，改写了已确认块；`GA(x2)` 要求切点 5。`x1` 与 `x2` 在前 10 段完全相同，所以任何只看「到下一个同级结构完成为止」的谓词无法同时满足两者。
- 展望无界：把 `s8`、`s9` 换成 `m` 段两两不相交、逐级上移且都高于 300 的小区间（不成核的前导段），两条延拓仍只在其后分叉，所需展望不小于 `m`。因此对任何固定展望长度都有反例。
- 该反例只用途径一的参考块语言与逐级三段成核。并入途径二后，同级终点还多一处依赖「下一个中枢何时出现」的无界视界，不会让冲突消失；但那种情形下的具体见证本文没有构造。

对照两个原典判例：

- `[099:22]` 的六段例取 `a = [0,10]`，`b = [6,10]`，`c = [6,16]`，`d = [12,16]`，`e = [12,22]`，`f = [14,22]`。在单中枢块语言下，`a`、`b`、`c` 成核 `[6,10]`，`d` 脱核，块 `[0, 3)`；`d`、`e`、`f` 成核 `[14,16]`。局部规范分解直接给出 `a+b+c` 加 `(d+e+f)`，无需回溯。
- 单层让位例（12 段加收尾）：`s0..s2 = [10,20]`，`s3 = [18,40]`，`s4..s11 = [30,40]`，其后 `[60,70]`。`LG = [0, 4, 12]`，全表没有升级块；而起于 3 的九段升级成立，切点表 `[0, 3, 12]` 能确立它。是否让前块在 3 处让位，由第 11 段决定，展望 8 段，属于命题 C 的有界范畴。

### 2.4 可落地的分层接口

**第一层 `IsLocalCanonical`（即默认的 `IsCanonical`）**

- 内容：每一级切点表满足「每步占优终点唯一且等于所选终点」加「末切点起不再成块」，最高一级从起点不再成块。这是乙方 `DeterministicBlocks` 的写法，加上 `W9` 既定的规则级前提「凡有合法终点则占优终点唯一」。
- 允许的优先：只允许本级有界视界的优先类别，由 `rank` 表达。
- 确认语义：接口律第 5 条只对这一层成立。M2 的 `Confirmed`、`RevisionCount`、`PendingCandidates` 都以这一层为准。
- 声明式要求：谓词写成对切点表的条件，不写成「等于某算法输出」（B-32）。

**第二层 `IsGlobalCanonical pref`（跨级结合律重组）**

- 内容：`ValidDecomp t` 成立，且不存在合法的 `t'` 使 `pref t' t`。
- 对 `pref` 的四条约束：只读各级原始切点表，不读证书；保序不变；镜像等变；是严格偏序。唯一性不作假定，需要时由定理层另加全序前提。
- 不带确认语义：这一层的输出是另一座塔，按 `#2318` 结论二它是另一份分解，不是对第一层的修订。它不得进入 `Confirmed`，不得用来声称修订量为零。
- 消费方：只供显式带分解参数的谓词使用（B-4；`[054:58]` 表明同一位置是否第三类卖点随分解而异）。M15 可在任一层的塔上求值，由调用方声明用的是哪一层。

**两层之间的定理义务（供定理层登记，本文不证）**

1. 第一层的分解存在即唯一。
2. 第一层的分解属于合法分解集合。
3. 两层结果的差异可用 `RevisionCount` 度量；`PendingCandidates` 可以含第二层的备选。

### 2.5 是否修改当前参数化与默认值

- **默认值要定下来**：`IsCanonical` 默认等于 `IsLocalCanonical`。对撞蓝图 5.2 第 11 行把「局部还是全局」留到 `#2296` 二选一，本裁定取消这个二选一：全局版不能当默认，因为它与接口律第 5 条相冲突（命题 B）。
- **参数化要收紧**：`pref` 的签名限定为只读切点表，并带上面四条约束。
- **留给 `#2296` 的一个开关**：单层让位（2.3 节 12 段例）是否启用。两种取值都满足前缀稳定；启用时前块的确认要多等至多 8 段。本文建议默认关闭，以保持与 `W11` 既定语义一致，不把它当作本项裁定的一部分。

## 三、M7 `CarryNineParams` 三分支组合相容性（对撞表第 64 项）

### 3.1 判定口径

- 三条定律：`InterfaceLaws` 重点看第 5 条（只对 `confirmed` 块要求前缀稳定，`W9` 既定）与切分唯一；`CarryBounded` 取 `W9` 既定的主口径，即块内单中枢连续延伸段数不超过 `K`，默认 `K = 9`；`DeterministicRule` 即「凡有合法终点则占优终点唯一」加起点定终点。
- 三个等级：**满足**指在一般交替序列上成立，且块可在有界展望内确认；**条件满足**指须补一条写明的条款，或须限定载体；**矛盾**指有显式有限反例，且在该组合的语义之内补不回来。
- 载体：矩阵按一般交替序列（允许跳空）判定；折线上的差别在 3.3 节单列。

硬证据：`[020:56]`（延伸等价于每段都与核重叠，有一段整体在核外则延伸终止）；`[018:64]`（破坏当且仅当离开后回抽不回中枢）；`[020:40]`（更大级别中枢产生前本级走势类型延续）；`[018:40]`（三段后随时可完成，也可继续延伸）；`[057:42]`（十段按三组各三段结合成高一级中枢）；`[099:26]`（划分须先保证高级别中枢确立）；`[038:26]`（不定义延伸、允许盘整接盘整属于同级别分解规则）；`[043:44]`（某级别走势类型内不出现更大的中枢）；`[017:60]`（上涨与盘整须含三个以上次级别运动）。

背景旁证：`[二级旁证 066:186]`、`[二级旁证 069:423]`（九段按三组各三段组合；九段延伸可看成三个次级别走势类型重合）；`[二级旁证 095:86]`（升级的两条途径）。这三条只说明分支的来历，下面的判定不依赖它们。

### 3.2 逐轴结论

**分支 A**

- A1（三段成核）：块长只有 3 或 9（另加前导段或进入段），延伸有界。但终点在第 9 段到齐或首个脱核段出现之前都可能被九段升级改写（`W9b`），所以 `confirmed` 必须延迟，至多多看 6 段。语义上它等于「同级别分解加进位」，与 `[020:40]`、`[038:26]` 对规范规则的要求不合，只能作对照档。
- A2（单段脱核）：终点在脱核段出现的那一刻确定，此后不变。它正是 `[020:56]` 的字面内容。
- A3（完整第三类破坏）：在折线上与 A2 逐点等价（3.3 节引理 5）。在允许跳空的交替序列上，「跳空离开后回抽回到核内」既不算破坏，M5 的中枢又无法把那个核外段并入覆盖，于是从该起点永远没有合法终点（反例 3）。按 `[018:64]` 与 `[020:56]`，破坏与否区分的是延伸终止之后的去向，而不是块在哪里结束。所以 A3 不应是成块时机的一档，它的证据应当用作 `confirmed` 的判据与途径二的入口条件。

**分支 B**

- B1（止于第 9 段）：升级块在第 9 段到齐时立即确认，零展望，无状态。
- B2（第 10 段强制进入段）：在 C2 下是冗余的，因为每块首段本来就是进入段。在 C1 下，同一起点的终点取决于前一块是不是升级块，起点单独不能定终点（反例 4）；并且强制进入段若触核，块内延伸达到 10 段（反例 5）。
- B3（延至下一次成核点）：升级块的终点要等到下一个成核点出现，展望无界；其间触核却不成核的段都被吞进升级块，块内延伸可超过任何 `K`（反例 6）；若此后不再成核，已经成立的高一级中枢永远不输出，与 `[099:26]` 相违。

**分支 C**

- C1（可含首段，带前导搜索）：首三段能成核就从首段起核，不能成核的前导段自然成为进入段。最小块是 3 段，与 `[018:40]`、`[017:60]` 一致，也能复现 `#2318` 八段例的 3 加 5 与 5 加 3。
- C2（独立进入段）：最小块是 4 段，三段即完成的盘整无法表示。进入段若触核，它与其后九段构成块内 10 段连续延伸，`K = 9` 的进位有界律被破坏（反例 5）；把 `K` 放宽到 10 才成立。

### 3.3 两条折线引理

**引理 4（折线上九段延伸必有三凸包公共交）。** 记三组凸包为 `H1`、`H2`、`H3`。`H1` 包含核。九段都触核，所以 `H2`、`H3` 各与核相交，从而 `H1∩H2`、`H1∩H3` 非空。折线上第 6 段与第 7 段共端点，所以 `H2∩H3` 非空。一维区间两两相交即有公共点。推论：在一般交替序列上，三凸包校验等价于 `H2∩H3` 非空；`W11a` 是纯跳空现象。

**引理 5（折线上 A2 与 A3 逐点等价）。** 设第 `k` 段是第一个脱核段，整体在 `ZG` 之上。若它向上，则它的起点是第 `k−1` 段的低点，于是第 `k−1` 段也整体在 `ZG` 之上，与 `k` 最小矛盾。所以它向下，起点是第 `k−1` 段的高点且高于 `ZG`；第 `k−1` 段向上、触核、越过 `ZG`，第 `k` 段向下且低点高于 `ZG`，正是修复后 M5 的连续离开型第三类事件。向下对称。

### 3.6 推荐默认组合与参数化修改

**面向 `#2296` 的推荐默认：第 7 组，即 A2 单段脱核、B1 止于第 9 段、C1 可含首段并带前导搜索**（对应甲方占位值 `coreBroken`、`afterNine`、`mayIncludeFirst`），`CarryBounded` 取 `K = 9`。

须随默认一并冻结的**封顶条款**：延伸满九段而三凸包不交时，块仍止于第 9 段，但记为普通块，不记为升级块。即「满九必截，升级与否只由三凸包校验决定类别」。说明三点：

- 它不改 `W11a` 的裁定。那里裁的是「不得当作升级」，封顶块正好不是升级块。
- 在折线上此条款永不触发（引理 4）。
- 另一种写法是退回三段截块。它也有界，但会让 8 段延伸成一块、10 段延伸反被切成 3 段，不单调，所以不推荐。

**可保留的相容子集**：A 取 A1 或 A2，B 只取 B1，C 取 C1；C2 仅在显式声明 `K = 10` 时可作对照实例。A3 在限定折线载体时与 A2 相同，没有独立保留的必要。

## 四、M15 一类点离枢阈与 `#2322` M17 接口边界（轴 `U-2`）

### 4.1 裁定

1. **M15 只锁出核。** 第一类买点的结构条件是离开段 `c` 严格低于最后中枢的 `ZD`；第一类卖点是严格高于 `ZG`。等号不算出核（分叉 4）。
2. **创新极值不进 M15。** 是否跌破 `DD`、突破 `GG`，以及一切「把 `c` 与此前的段相比」的条件，统一由 `#2322` M17 的 `StrengthJudge` 承担。
3. **不设 `FirstExitThreshold` 的波动区间档。** 主线 `Chan/Defs` 里一、二类点谓词不出现 `DD` 与 `GG`。甲方的 `DD` 口径只留在审计分离条目（对撞报告 3.2 节已列 `M15_FirstBuyDDvsZDAndFakePrev`）。

硬证据：`[017:60]`（第一类买点是下跌走势完成转化的关节点）；`[053:28]`、`[101:20]`（第一类买卖点就是背驰点）；`[017:70]`、`[017:72]`（转折由某级别第一类点构成，某级别不一定是次级别）；`[020:54]`、`[020:56]`（核 `[ZD, ZG]` 在延伸中不变，延伸按与核重叠判定）；`[070:48]`（结构的结束位置不必是最高或最低点）；`[054:24]`（相触算震荡，严格越过才算离开）；`[086:76]`（转折后第一段反弹可同时构成最后中枢的第三类卖点）；`[101:22]`、`[101:28]`、`[101:32]`、`[101:38]`（二买及其强弱三分）。

这些条目都没有把「跌破波动区间低点」写成第一类买点的形态学要件。背驰属于力度判定，按分叉 3 只能经抽象参数接入。

### 4.2 理由一：`DD` 阈在修复后的 M5 上自指

核 `[ZD, ZG]` 成核时即固定，延伸中不变。波动区间 `[DD, GG]` 是覆盖段的凸包，随延伸单调扩张。按 `W8` 既定的修复，连续离开段起于核内、与核重叠，它本身就是覆盖的最后一段。于是：

- 覆盖含 `c` 时，`DD ≤ c` 的低点恒成立，「`c` 的低点 `< DD`」永假。
- 要让 `DD` 阈有意义，只能取「不含 `c` 的覆盖」的 `DD`。这是把 `c` 与此前各段的极值相比，是比较型条件，而且多出一个「覆盖截到哪里」的自由度。

显式反例。取 `W17a` 的下跌趋势：中枢 `B` 为 `s4 = (上,[10,25])`、`s5 = (下,[5,20])`、`s6 = (上,[10,20])`，核 `[10,20]`；把离开段改为 `s7 = (下,[3,20])`。

- 覆盖取 `s4..s6`：`DD = 5`，`3 < 5`，`DD` 口径判为可作一买的离开段。
- 覆盖取 `s4..s7`（`s7` 触核，是合法延伸段，也是 `W8` 连续离开的写法）：`DD = 3`，`3 < 3` 为假。

同一走势、同一中枢、两种都合法的覆盖，`DD` 口径给出相反结果。`ZD` 口径两次都是 `3 < 10`，与覆盖怎么取无关。

### 4.3 理由二：出核而未破 `DD`

`W17a` 原例：`A` 为 `s0..s2 = [40,50]`，`b = s3 = (下,[20,40])`，`B` 的核 `[10,20]`、波动区间 `[5,25]`，`c = s7 = (下,[8,20])`，其后 `s8 = (上,[8,15])`，`s9 = (下,[11,15])`。此时 `DD = 5 < 8 < 10 = ZD`。

- 结构上：`A`、`B` 构成下跌趋势，`c` 是最后中枢之后的离开段，严格出核。`c` 的终点是不是转折的关节点，只剩力度问题：`b` 幅度 20，`c` 幅度 12，背驰与否该由 M17 说。
- 若 M15 硬锁 `DD`：这里没有一买，二买因以一买为前提（`[101:22]`）也没有，整个中阴阶段在该级别上成为空白。M15 等于替 M17 预先否决，而否决的依据不在引文包里。`[070:48]` 明说结构的结束位置不必是最低点。
- 若 M15 只锁 `ZD`：M17 的极值条件若成立则有一买，不成立则没有，两种结果都由 M17 负责，M15 不抢判。

### 4.4 理由三：破极值、离开段终结与二三类点的衔接

1. **与第三类卖点的阈一致。** `[086:76]` 的情形是：`c` 向下离开最后中枢并转折，第一段反弹的高点仍低于 `ZD`，构成该中枢的第三类卖点。第三类卖点对离开段的要求是低点严格低于 `ZD`（`W8`、`W19`）。一类点若也取 `ZD`，两族谓词对同一段 `c` 用的是同一个阈，可得对齐引理：以 `c` 为离开段的第三类卖点成立，则 `c` 满足一买的结构出核条件。若一类点取 `DD`，在 4.3 节的例子里把 `s8` 改为 `(上,[8,9])`，则 `s7`、`s8` 构成 `B` 的第三类卖点，而 `s7` 却没有资格当一买的离开段，两族错位。
2. **二买强弱三分不用 `DD`。** 最强档比较回试低点与 `ZG`，较弱档比较二买与一买的价位，中间档是其余情形。`DD` 在一、二、三类点的整条链上只会在一类点处出现一次，是孤立阈。
3. **破 `DD` 时两种口径一致。** `c` 的低点低于「不含 `c` 的覆盖」的 `DD` 时，因 `DD ≤ ZD`，必然也出核。所以「M15 锁 `ZD` 加 M17 判极值」恰好等于甲方的 `DD` 口径，而 `DD` 只在 M17 判一次，没有重复。
4. **离开段在哪里终结不归 M15。** `c` 的终点由 M4 与 M6 的分段和分解决定；M15 只在给定分解的切点上求值（B-4）。

### 4.5 M15 与 M17 的接口契约

**M15 负责（全部是可判定的几何与结构条件）**

- S1：分解中有一个在该切点结束的完成块，其同级中枢序列按 M9 分类为下跌趋势（卖点为上涨趋势）。
- S2：`z` 是该块最后一个中枢；`c` 是 `z` 之后、块内最后一段，收笔方向向下（深度 0 即段方向）。
- S3：`c` 严格出核，低于 `ZD`。取段极值还是取收束端点，按轴 `U-3` 的结果，本裁定不涉及。
- S4：比较段 `b` 唯一锚定为最后两个中枢之间与 `c` 同向的连接段（`W17` 既定）。
- S5：该切点处于中阴阶段。
- S6：在 S1 至 S5 都成立时调用 `judge`，传入分解、`z`、`b` 的下标、`c` 的下标（`W17` 既定签名）。一买为 S1 至 S5 与 `judge` 结果的合取。

**M17 负责**

- 极值条件：`c` 是否创出新极值，参照集由 M17 定义。建议参照「`z` 的覆盖中严格先于 `c` 的各段」与 `b` 的极值；所需数据都能由 S6 传入的参数算出。
- 力度比较本身，以及 `[053:28]` 所说小级别转大级别的例外。

**不重复、不错位的四条约束**

1. M15 的一、二类点谓词不读 `DD`、`GG`。
2. `judge` 不重验 S1 至 S5，可以把它们当作前提；也不得放宽 S3。
3. `judge` 须满足镜像等变（买卖两侧经多空对偶得到同一结果）与因果性（只依赖该切点之前的数据）。这两条作为 `#2322` 实例的命题义务登记，不写进 M15 的定义。
4. M17 把极值条件单独暴露为可判定谓词并写明参照集，便于审计层检验「极值成立蕴含出核」。
