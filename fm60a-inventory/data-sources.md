# #2324 历史行情来源调查报告

调查日期 2026-11-26。只读调查，没有拉任何行情数据，没有注册、没有付费，检索词未带项目信息。

## 结论（先看这里）

1. **61 条判例的需求高度集中在上证指数 1 分钟线**，时间窗 2007-01 至 2008-03（约 26 条判例），其次是 2008-03 至 2008-09 的上证 30/60 分钟线（约 16 条）。个股与权证只有约 10 条。
2. **仓内没有可用的数据管线**：现有取数代码只面向近期数据（akshare 东财分钟线、新浪 1023 根上限、IBKR/Databento 美股期货），仓内文件自己写明东财 1 分钟只存最近约 5 天。**2003 至 2008 年的 A 股分钟线仓内完全不能覆盖**；日线可借 yfinance（上证指数自 1997-07）。
3. **免费接口里没有找到 2007 至 2008 年的 A 股指数分钟线**：AKShare 与新浪、东财只回溯近期；BaoStock 文档写明指数没有分钟线；Tushare 指数分钟自 2009 起且要单独买权限；掘金 SDK 分钟线自 2017 起。
4. **能覆盖 2007 年的只有付费或需注册的来源**：米筐 RQData（官方 PDF 写明指数分钟 2005 起）、聚宽 JQData（只读到旧博客转述，官方页被地域限制挡住）、通达信格式的第三方历史包与掘金数据等商业售卖包。这些我都没能核实价格与许可。
5. **口径风险大**：各软件分钟标记、集合竞价归属、四舍五入不同；0.08 点级判例（FM60A-031）必须拿到与原文同一软件的数据才有意义，这一条很可能最终只能标不可回归或「数据不可核」。

## 2. 仓内现状

仓内没有任何 2003 至 2008 年的行情数据文件，清点表 README 同样记载（`fm60a-inventory/README.md` 第 5 点）。我读到的现状如下。

| 管线 | 文件 | 覆盖 | 对 2007 年 A 股有用吗 |
|---|---|---|---|
| akshare 东财接口 | `src/newchan/data_astock.py`（文件头：`stock_zh_a_hist_min_em` 取 1/5/15/30/60 分钟，`stock_zh_a_hist` 取日线，支持 qfq/hfq） | 个股近期分钟线，个股日线 | 分钟线不行；日线可用于个股，**不含指数** |
| akshare 新浪/东财 | `scripts/fetch_china_1m.py` 文件头写明：「新浪期货分时对所有周期只返回最近 1023 根 K 线（≈4 个交易日）」「东方财富 1min 本身只存最近 ~5 天」 | 沪深 300 期货等 | 不行（仓内自己的结论） |
| baostock | `scripts/fetch_a_shares_daily.py`：「免费，无需 API key」，只取个股日线，输出 `data/scanner_l2/{code}_daily.json` | 个股日线 | 个股日线可用；该脚本不取指数、不取分钟 |
| yfinance | `analysis/hk_china_index_backtest_shcomp.md`：`000001.SS` 日线 1997-07-02 至 2026-05-29（7001 根）；1 分钟只有 7 日窗口 | 上证指数日线 | 日线可用，分钟线不行 |
| IBKR TWS | `scripts/tws/fetch_1m_tws.py`、`fetch_30m_tws.py`，`src/newchan/data_ibkr.py` | 美股/期货，近年 | 不行 |
| Databento | `src/newchan/data_databento.py`：期货 1 分钟自 2010 起，美股自 2018 起 | 美国市场 | 不行 |
| 中国平台态度 | `docs/quant-platform-research-2026.md:463` 把聚宽、米筐、掘金、天勤、QMT 列为「纯中国 A 股市场基础设施」而排除 | — | 仅说明项目没有采用，并非不可用 |

数据格式：仓内通行的是列式 JSON `{symbol, dates, opens, highs, lows, closes, volumes}`，存在 `analysis/data_cache/` 或 `data/scanner_l2/`（见 `fetch_1m_tws.py` 文件头）。`pyproject.toml` 中依赖有 `akshare>=1.14`、`ib_insync`、`databento`，没有 tushare 与 pytdx。`rg` 命中 tushare、通达信、聚宽的文件只有 `docs/quant-platform-research-2026.md`、`scripts/scanner_l2_validation.py`、`tests/test_tightness_proxy_consistency.py`、`analysis/genealogy_parts/part-05.md`，我未逐个展开，没有看到可用的取数代码。

**结论：现有管线对 2003 至 2008 年的 A 股，只有「个股日线（baostock/akshare）」与「上证指数日线（yfinance）」可能够用；周线月线可由日线聚合；所有分钟线都不能覆盖。**

## 3. 外部来源

### 3.1 AKShare
- 指数分钟接口 `index_zh_hist_min_em`（东财）：文档写「其中 1 分钟数据只能返回当前的，其余只能返回近期的数据」「该接口不能返回所有历史数据」。【已读】https://akshare.akfamily.xyz/data/index/index.html （页面文本只读了前 100000 字，不含全部接口）
- 指数日线：`index_zh_daily_sina`「返回所有历史数据」，起点是新浪数据起点；`index_zh_daily_em`、`index_hist_csindex` 也是日频。【已读】同上。
- 免费，不需注册，是对东财、新浪、腾讯网页接口的封装，许可跟随各上游站点条款，我没有找到明确的研究或再分发条款：【未核实】。
- 结论：**2007 至 2008 年指数分钟线：没有**。指数日线可取全历史（具体起点需取数时验证）。

### 3.2 BaoStock
- 官方 API 文档镜像：`frequency` 取值 d、w、m、5、15、30、60；「指数没有分钟线数据」「“分钟线”不包含指数」；复权用「涨跌幅复权法」，「不同系统间采用复权方式可能不一致」。【已读，GitHub 镜像】https://github.com/lzwme/finance-quant-skills/blob/main/skills/baostock/references/markdown/pythonAPI.md
- 个股分钟线自 1999-07-26、指数自 2006-01-01、日周月线自 1990-12-19：这些年份我只在检索摘要里看到。该镜像页面里没有这几个日期，官方站 `https://www.baostock.com/mainContent?file=pythonAPI.md` 我取不到正文。【转述，未核实】
- 免费、无需令牌（仓内 `fetch_a_shares_daily.py` 文件头同说法）；许可条款【未核实】。
- 结论：**个股 5/15/30/60 分钟可能回溯到 1999（未核实），1 分钟没有，指数分钟线没有。** 对本票：中国人寿 5 分钟（009、010）值得一试；上证指数 1/5/30/60 分钟都不行。

### 3.3 Tushare
- `idx_mins` 指数历史分钟：「起始时间 2009-01-01」「本接口数据需单独开通权限」「单次最大 8000 行」「超过 10 年历史分钟数据」。【已读】https://tushare.pro/document/2?doc_id=419

- 结论：**分钟线最早 2009，覆盖不了 2007 至 2008。** 日线、周线、月线（指数与个股）需积分，门槛未核实。

## 5. 建议

### 5.1 按取数难度分档（对应需求表）

**A. 可以免费直接取到（无需注册）**
