# 原典修订台账

本台账依据 `#2323`（FM-10f）及门禁 16 第 5 条维护，记录每一组引出 `Chan/Defs/` 主线定义修订的 B 类审计组号与修订摘要。

- **B-1**（#2323）：统一高一级中枢唯一定义为“三个连续本级别走势类型存在公共重叠”，将“延伸满九段升级（3+3+3）”确立为规范化进位公理，规则甲降格为未规范化写法、规则丙单列为同级别规范分解方案。
- **B-2**（#2323）：废除“三段相连必有重叠”的隐含恒真假设，主线 `Chan/Defs/` 中所有三段重叠一律显式写为数据判定谓词，并将 `067:16` 改为带线段终止前提的待证引理。
- **B-3**（#2323）：统一写死五个谓词的等号边界口径——中枢重叠取闭区间（单点亦算）、第三类买卖点取严格不等（`低点 > ZG` / `高点 < ZD`）、K 线包含取非严格（一端相等即包含）、背驰力度取“不大于”、价格取绝对精确比较。
- **B-4**（#2323）：拆分合法分解集合 `Dec(w)` 与规范分解函数 `can(w)`，将买卖点谓词显式参数化为 `P(w, d)`（默认取 `can(w)`），不再宣称无规则前提下的绝对唯一分解。
- **B-5**（#2323）：主线抽象核对递归基底做参数化处理，抽象为任意产出“方向交替区间序列”的构造器，分型-笔-线段、三根 K 线重叠与三笔同价成交均作为具体实例接入。
- **B-6**（#2323）：线段划分改写为输入“笔序列 + 起点”的确定性双情况状态机，明确写死第一种情况分界点两侧禁包含与第二种情况允许包含的范围，缺口统一退回 K 线层处理。
- **B-7**（#2323）：成笔规则参数化为 `PenRule(包含处理后最少间隔, 原始K线最少间隔)` 以同时覆盖老笔与新笔，并用含回溯的确定性算法补齐同类分型筛选与相等保留的空白规则。
- **B-8**（#2323）：主线价格比较采用精确相等与精确序，取整或量化作为显式单调预处理映射参数传入，废弃不具传递性的 `0.5` 点容差等价说法。
- **B-9**（#2323）：直接修订抽象核输入结构——由“首尾相连的折线”改为“方向交替的闭区间序列”，仅依赖方向与值域 `[低, 高]`，消除端点非极值标准化导致的折线断开问题。
- **B-10**（#2323）：第二类买卖点采第 101 课版本四纯位置定义（允许二买低于一买），按强弱三分法刻画，“必成更大级别中枢”改写为附带重叠前提的条件定理。
- **B-11**（#2323）：收束第三类买卖点五项分散要件（最近中枢、至少五段、已完成次级别离开与回试、严格不触中枢核心区间），最低级别改名 `ThirdBuyLike`，并将单一价位突破回试抽为 `BreakRetest` 与分型边沿分离。
- **B-12**（#2323）：买卖点安全性定理移除“100% 获利 / 必续涨跌”强断言，仅保留带前提的弱结构结论（若其后形成该级别中枢，则存在价格不低于买入价的时刻）。
- **B-13**（#2323）：买卖点谓词族按中阴阶段（一买卖、二买卖及其后回试点）、中枢震荡阶段（盘整背驰震荡买卖点）、离开阶段（三买卖）重构，完备性改写为纯结构起终点覆盖命题。
- **B-14**（#2323）：第三类买卖点谓词与趋势上下文分离（显式区分是否处于一买后底部构造阶段，或保持纯结构谓词并移除“必继续向下/向上”结论）。
- **B-15**（#2323）：分立趋势背驰 `TrendDiv`（需至少两中枢）与盘整背驰 `RangeDiv`（围绕同一中枢两次同向离开）两个谓词，共用力度比较接口、各自陈述独立结论。
- **B-16**（#2323）：强制背驰谓词 `Div(t)` 仅依赖截至时刻 `t` 的因果可观测数据，与事后转折确认 `DivConfirmed` 彻底分离，消除 `079:52` 事后定义循环。
- **B-17**（#2323）：收窄背驰保证为单一公理/待检验命题“回拉至最后一个中枢区间”，将 `029:16` 背驰-转折定理三种结局改写为回拉后的完全分类，移除无条件“必然”。
- **B-18**（#2323）：趋势终结定义修订为互斥穷尽三情形——（1）存在 `c` 段且 `TrendDiv(b, c)`；（2）无 `c` 段而 `B` 内 `RangeDiv` 后反向离开；（3）`B` 出现反向第三类买卖点；第一类买卖点仅对应情形（1）。
- **B-19**（#2323）：背驰比较段规定由规范分解 `can(w)` 唯一给出，并将力度函数抽象为独立接口（MACD 柱面积作为其具体实现之一）。
- **B-20**（#2323）：区间套改写为纯结构的嵌套时间区间引理，将“每一级内部均存在同级别背驰”单列为附加前提，不再默认排除小级别转大级别。
- **B-21**（#2323）：拆分“小转大”两义，在主线定义中分立 `SmallToLarge`（小级别背驰引发大级别转折）与 `TrendEndByThirdBuy`（第二中枢反向三买卖终结趋势）。
- **B-22**（#2323）：趋势定义仅保留 `017:46` 中枢计数版（同级别同向不重叠中枢数 `≥ 2`），将 `107:32`“第一中枢后三买 + 非背驰向上”另立为前瞻谓词 `TrendForming`。
- **B-23**（#2323）：走势类型完成后主线仅证同级别交替性定理，“面临至少大一级别中枢震荡”补充三段公共重叠前提（`T3` 与 `T1` 重叠）后作条件定理。
- **B-24**（#2323）：主线不再使用多义统称“走势必完美”，拆分为四个独立命名命题：活性公理、结构下界定理、级别无关性（总缝规则 `#804`）、规范分解唯一性定理。
- **B-26**（#2323）：主线级别统一表示为二元组 `(基底, 递归深度)`，禁止跨基底直接等同，并将按图周期定义的“分型意义级别”与走势类型级别异名分立。
- **B-27**（#2323）：主线建立一词一义术语表，对“扩展/扩张”、“次级别”、“`Zn`”（Z 走势段 / 震荡中轴 / 周线记号）、“底部”（走势类型版 / 分型版）与“线段”全部消歧并改名隔离。
- **B-28**（#2323）：将理论“精确性”口径严格限定于三处：已完成结构的规范分解、买卖点的点位判据、未完成走势的有限候选完全分类。
- **B-29**（#2323）：将基底构造器与规范分解规则作为可替换参数纳入架构，剔除缺乏目标函数的“现行设计唯一最好”断言。
- **B-30**（#2323）：补齐显式公理清单（活性公理、基底公理、进位公理、动力学假设），并将每条原典断言归类标注为“定义 / 可证 / 公理 / 不可证”。
- **B-31**（#2323）：撤除“背驰必转折存在原典严格证明”的假定，将动力学力度抽为接口，把背驰回拉结论显式归入动力学公理或经验待检验命题。
- **B-32**（#2323）：在显式确立进位公理后，将“类记数法唯一分解”正式定义为多级别（连接段，中枢）嵌套树的规范形存在与唯一性定理。
- **B-36**（#2323）：主线将分型边沿跌破/站稳严格限定为成笔的必要条件，成笔充分条件必须连同包含处理与 K 线根数间隔条件一并写全。
- **B-37**（#2323）：中枢震荡终将越界的结论改写为条件命题（若震荡结束则必有次级震荡越界），无条件版本显式声明依赖活性公理。
- **B-38**（#2323）：修订两同级别中枢相对位置分类，改用区间全序完备枚举核心重叠、外缘重叠与完全分离全部情形；并补记 `093:26` 原文缺失的第二类情形。
- **B-42**（#2323）：订正原典三处关键笔误对主线定义/证明的影响——`077:44` 笔唯一性证明“不低于”订正为“不高于”、`017:66` 买卖点定律一补齐卖点侧、`052:22`“背驰级别不小于转折级别”订正为“转折级别不小于背驰级别”。
