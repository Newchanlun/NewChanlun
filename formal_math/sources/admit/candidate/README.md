### (b) `passes_agree` 与 `adjudicated` 两个字段

- `passes_agree`：**合并之前**，甲、乙两遍各自标注的 `author_spans` 是否逐段完全相同。`false` 共 3 条（743、760、778），即上文「三条分歧」。它只说明两遍当时意见不一，不说明谁对；这 3 条最终取两遍交集，也就是任一遍剔除的字都不收。
- `adjudicated`：该条是否被 `adjudications.json` 的 `exclude` 里主控按实物审再剔除过字符。`true` 共 4 条（137、138、743、877）。这类处置只剔除、不恢复；`declined` 里未采纳的建议（如 760 的「（请看下图）」）不使该字段为 `true`。
- 两个字段互相独立，组合现数：两遍分歧且被再剔除 1 条（743）；分歧未再剔除 2 条（760、778）；两遍一致但被再剔除 3 条（137、138、877）；两遍一致且未再剔除 784 条（含裁剪的 132、929、1259 与 781 条 `clean`）。
- 注意 `passes_agree == true` 不等于「两遍都认为干净」：它只表示两遍的区间相同，132、929、1259 就是两遍一致认为要裁剪。
