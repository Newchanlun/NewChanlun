## 一、`U-1`：M16a `maAvgForce`（见证 `W5`）

### 1.1 裁定

1. **`maAvgForce` 取选项 B**：闭窗 `[s, e]` 上两均线之差的绝对值之和，除以柱数 `e + 1 − s`，并以证明参数强制 `s ≤ e`。带号版 `maSignedAvgForce` 并列保留。
2. **两者分工**：无向版是用来比强弱的量；带号版是端点差恒等式的载体，不直接拿去做大小比较，要比较须先按方向取号。
3. **定义域声明**：原文的窗口是相邻两次吻之间的一段，这种窗内均线差不变号，下称同侧窗。同侧窗上无向版恒等于带号版的绝对值。跨吻窗不在原文的定义域内，两个函数在其上都只是代数延拓；凡引用 `[015:42]` 的命题都必须带同侧窗前提。
4. **时长取柱数**：每根柱记一个单位时间，矩形求和，分母为 `e + 1 − s`。单柱窗分母为 1。

硬证据：`[015:42]`（两条）；`[024:24]`（柱面积按颜色读，即只读本侧的非负量）。

### 1.2 论证

**(1) 原文窗口本身不跨吻。** `[015:42]` 「当下与前一“吻”的结束时短线均线与长期均线形成的面积除以时间」。本文的读法是：一次吻结束到下一次吻之前，短线均线始终在长线均线的同一侧，差值不变号，所以这段面积既等于带号和的绝对值，也等于绝对值之和；两个选项只在原文没有定义的窗上才分开。吻的定义条目不在本包内，这一读法没有包内硬证据（见第十一节）；下面第 2、3、4、6 点不依赖它。

**(2) 空头窗里带号版把强弱比反了。** `[015:42]` 的比较语是「一旦这次比上次弱」，同一句给出的结论是「真正的低部马上形成」，所举的正是下跌。下跌窗里带号值为负：若上一次是 `−6`、这一次是 `−3`，力度在减弱，而数值上 `−6 < −3`，按小于号读会把更强的上一次判成更弱。`W5a`（差值 `−2, −4`）带号版得 `−3`，无向版得 `3`。`[024:24]` 「向上的看红柱子，向下看绿柱子」是同一种读法：每一侧只读本侧的非负面积。

**(3) 镜像下的行为。** 价格取负时两条均线取负，差值变号：带号版变号，无向版不变。所以无向版不带方向参数就是多空对称的；带号版必须配方向才能比较。

**(4) 端点差恒等式留在带号版，不因选 B 丢失。** 对任意平滑系数 `α`，指数均线满足 `x(t) − ema(t) = ((1−α)/α)·(ema(t) − ema(t−1))`。于是对 `s ≥ 1`：

`Σ_{t=s..e} (fast(t) − slow(t)) = c_slow·(slow(e) − slow(s−1)) − c_fast·(fast(e) − fast(s−1))`，其中 `c = (1−α)/α`。

标准周期 12 与 26 下 `c_fast = 11/2`、`c_slow = 25/2`。记 `Ψ = c_slow·slow − c_fast·fast`，则带号面积是 `Ψ` 的带前驱端点差，无向面积是 `Ψ` 在该窗上的全变差，也就是向上与向下两个正变差读数之和。同侧窗上带号面积的绝对值与无向面积相等。

**(5) 附带事实（供 `U-8` 使用）。** 首值播种下对匀速价格 `x(t) = v·t`，`ema(t) = v·t − c·v·(1 − (1−α)^t)`，故均线差趋于 `(c_slow − c_fast)·v`，标准周期下是 `7v`。也就是说 `[015:42]` 的趋势平均力度，在匀速段上就是速度的常数倍。

**(6) 除零。** 现稿以 `s ≤ e` 的证明参数挡住空窗，分母恒正，符合门禁对除零垃圾值的要求。

### 1.3 边界例

- `W5a`（纯空头窗）：`maS = [8, 6]`，`maL = [10, 10]`。带号 `−3`，无向 `3`。
- `W5b`（跨吻窗）：`maS = [12, 8]`，`maL = [10, 10]`。带号 `0`，无向 `2`。此窗不是同侧窗：带号版把两侧面积抵成零，无向版把两个方向的面积加在一起，原文对这两种读法都没有授权。裁定不在这里选边，只要求调用方带同侧窗前提。

## 二、`U-2`：M17 `ConsolDiv`（见证 `W13`）

### 2.1 裁定

1. **取选项 C**。`ConsolDiv` 收两种结构窗：
   - **入枢窗**：紧邻中枢之前、与 `c` 同向的进入段 `a`，对成枢后的离开段 `c`。
   - **再离窗**：同一中枢同一侧相邻的两次出核离开，中间须有反向段触核。
2. **两窗是两个各自独立的结构前提，不是一个判断的宽严两档。** 窗在力度比较之前就由分解确定；调用方用 `spec.window` 指名要检验的那一窗，`matchesWindow` 只放行与之相符的结构窗。任何一窗不成立，不得改拿另一窗的结果顶替。这样才不违反收敛通则 `#799`。
3. **`ConsolDiv` 的真值是相对于窗的。** 两窗同时存在时可以一真一假（2.3 节例三），不存在脱离窗的单一盘整背驰结论；下游凡消费 `ConsolDiv` 的定义都必须说明用的是哪一窗。
4. **再离窗只取相邻的那一次**（最近一次同侧离开）。更远的两段照 `[061:26]` 仍然可以比，但走通用的 `forceWeaker` 加调用方自选窗口，不记作 `ConsolDiv`。这是为了满足 B-19“比较窗口由规范分解唯一给出”。
5. **不松动 B-15**。`ConsolDiv` 只在作用域内恰有一个同级中枢时成立，仍与 `TrendDiv` 分立。

硬证据：`[027:16]`、`[027:20]`、`[061:26]`、`[033:26]`（三条）、`[033:30]`、`[098:16]`、`[015:36]`、`[027:14]`。

背景旁证：`[二级旁证 044:234]` 「未创新高的情况，其实可以按中枢震荡的方式去看，等于达不到上次震荡的力度」，这里拿来比的是上一次震荡，与再离窗同型。

### 2.2 论证

**(1) 入枢窗有直接出处。** `[027:20]` 「把第一、三段看成两个走势类型之间的比较」，第一段是进入，第三段是离开。

**(2) `[061:26]` 的通则两窗都盖，它自己举的例子却是入枢窗。** 通则是 `[061:26]` 「只要是围绕一中枢的两段走势都可以比较力度」。紧接的例子是 `[061:26]` 「对于60-65这个1分钟中枢，55-60与65开始的一段之间就可以比较」：按标号顺序读，`55-60` 在这个中枢之前，`65` 开始的一段在它之后，是进入段对离开段。对撞报告把 `[061:26]` 只挂在选项 B 名下，与这个例子不符。所以只收再离窗（选项 B）与 `[027:20]` 和 `[061:26]` 自己的例子都冲突；只收入枢窗（选项 A）则与 `[061:26]` 的通则冲突。

**(3) 再离窗的技术含义就是盘整背驰的定义。** `[027:16]` 说盘整背驰是「企图脱离中枢的运动，由于力度有限，被阻止而出现回到中枢里」。每一次出核后被拉回都是这样一次运动，下一次同侧离开拿它作参照，正是通则允许的围绕同一中枢的两段。

**(4) 对同一结论，两窗都是合格前提，所以并集是正确的前件。** `[098:16]` 对盘整背驰与趋势背驰给的是同一个结论（回拉原来的中枢）。`[033:26]` 与 `[033:30]` 的论证是：同一中枢对两段的回拉相同，较弱的那段既然不强于已被拉回或已被吸收的那段，也会被拉回。这个论证对入枢段与对上一次同侧离开都成立（本文的读法：`[033:26]` 是把进入段当作一次反向离开来比的）。前件取两者之并，B-17 的条件命题才不漏情形。

**(5) 为什么不构成宽档接管严档。** 两窗的结构条件互不蕴含：`W13a` 只有入枢窗，`W13b` 只有再离窗。现稿的 `passes` 先要求 `spec.window` 与结构窗相符，再独立检验创新极值与力度减弱，窗由调用方事先指名，不存在先试一窗、失败再换一窗的求值路径。

背景旁证：`[二级旁证 051:246]` 「反抽到1分钟以下级别的中枢里，这当然被理论所保证」。

### 3.2 论证

**(1) 对转折强度的单调性。** 向上一侧，把后缀里任一价格换成更低的价格（仍不创新高），越沿口径的真值不会由真变假。落核口径没有这个性质：`W15` 中核为 `[10, 12]`、离开极值 `15`、后缀 `[8]`，价格一步跌穿整个核，落核判假；此后若一路下行不再回到 `[10, 12]`，落核口径永远不确认。而 `[029:16]` 列出的三种后果里，这恰是最强的一种。确认谓词不应在转折更强时反而失效。

**(2) 对采样加密的不变性。** 在线条件已保证当下价格严格在核沿之外（现稿 `trendWindow?` 与 `consolWindows` 都有这条守卫）。于是：后缀中有样本越沿，当且仅当把样本逐点连成折线后，折线与闭核相交（折线从 `ZG` 上方出发，到达 `ZG` 或其下方必经过 `ZG`；反过来线段上的最小值在端点取到）。所以越沿口径等于“连续插值触核”，在相邻样本之间插入中间价不改变它。落核口径会变：`W15` 在 `15` 与 `8` 之间插入 `11`，就由假变真。同一段行情换一个采样粒度得到相反结论，与总缝规则 `#804` 的要求相悖。

**(3) 原文承认跳空。** `[033:24]` 「b完全可以是一个跳空缺口」。离散样本越过一段价格区间而不在其中留点，是原文认可的走势，不是可以排除的病态输入。

**(4) 基准模型自身就会跳穿。** `#2322` 评论 1 的模型 A（核 `[−1, 0]`，`ρ = 1/2`，`γ = 2`，`x_0 = 1`，`v_0 = 0`），取 `f = [3, 0, 0, …]`，轨道是 `1, 2, 1/2, −9/4, −13/8, 11/16, −5/32`：第 3 步从 `1/2` 直接到 `−9/4`，越过整个核，直到第 6 步才第一次落核。再取核 `[−1, 1]`、无阻尼、区间外回复力恒为 4、零外力、从 `x_0 = 2` 静止出发，轨道以 4 为周期取 `2, −2, −2, 2`，每两步越沿一次，却永不落核。后一个例子满足一致下界回复、零推力预算与二阶差分有界三条，所以落核形态的回拉结论不能从 M19a 的五项假设推出，越沿形态可以（7.2 节命题）。

**(5) 原文保证的形态是阈值，不是落点。** `[029:30]` 「该反弹一定触及最后一个中枢的DD=min(dn)」：保证的是触及一个价位，属半平面形态，而且阈值是波动区间的沿，比核沿还弱。`[098:16]` 「理论只能保证其回拉原来的中枢」与 `[027:16]` 用的是中枢二字。两处的强度并不一致，这是原文内部的张力，本文不替原文抹平：确认谓词是事件定义，不是保证定理，取核沿是允许的；但将来任何“背驰后必回拉”的定理都必须写明取的是波动区间沿、核沿还是落核。

**(6) 对趋势终结三分的影响。** 按现稿 `Divergence.lean:283-294` 的分支次序，第一分支（独立 `c` 的趋势背驰）要求 `DivConfirmed`；不成立才往下落到直接反向第三类点。落核口径下，趋势背驰后一步跳穿核再出反向第三类点的走势，会因为没有样本落核而被标成第三分支，也就是被记成没有背驰的终结。同一种终结机制的标签不应取决于某个样本是否碰巧落在核里。

**(7) `[079:52]` 的要求不受影响。** 两个口径都保留“后缀不得再刷新离开段极值”这一条，合力把可能的背驰破坏掉的情形两者都判假。

## 四、`U-4`：M17 `NestedDivChain`（见证 `W17`）

前提照任务所给：顶层须是 `DivSegment`，下层须满足 `observedSpan`。

### 4.1 裁定

- **(a) 级别递增：允许跳层。** 相邻两项只要求层深严格下降（`j < k`）。
- **(b) 跨度嵌套：取非严格 `SpanWithin`。** 允许内外端点相等。
- **相邻逐级且真包含**（`k = j + 1` 且 `u ≠ v`）保留为现稿的 `StrictNestedDivChain`，定位是 `[027:38]` 所述理想情形的字面档，不作主谓词。

硬证据：`[027:38]`、`[027:40]`、`[027:44]`、`[027:46]`、`[056:66]`、`[061:26]`、`[061:34]`、`[043:26]`、`[033:24]`（跳空一条）。

### 4.2 论证

**(1) 主谓词应当是一个传递关系上的链。** 记相邻两项的关系为 `R((k,u),(j,v)) := j < k ∧ v ⊆ u`。`R` 是传递的，所以沿 `R` 的链就是两两可比的套：从中删去任何非首项，剩下的仍是合法的链。选项 B 的关系（`k = j+1` 且真包含）不传递，链不对删项封闭，这使“取一条区间套的子套”这样最基本的操作都没有定义。

**(2) 跳层是 `[056:66]` 的直接要求。** `[056:66]` 「完全可以不必有该级别的背驰，完全可以小级别转大级别」。现稿已经不要求中间层有背驰，但只有允许跳层，才能在主谓词之上再谈“各项都是背驰段”的加强链：中间层没有背驰时，这样的链必须跨过它。强制相邻逐级，就只能在链里混入不是背驰段的项。

**(3) 层深是相对于级别规则的。** 按 `#2295` 分叉 1，级别规则是显式参数。同一段行情在较细的规则下层数更多，一种规则里的相邻两层在另一种规则里隔着一层。把 `k = j + 1` 写进主谓词，等于让定义依赖层号的算术，与总缝规则“级别只作输入值”不合。

**(4) 非严格包含是最低级别不可再分的直接后果。** `[027:40]` 「这些级别不是无限下去的」。离开段在上一层是一个待定段，在下一层可以恰好是同一个原始跨度（下一层在这段时间里还没有完成任何一段，或者这段本身就是一步跳空，见 `[033:24]`）。这时两层跨度相等，真包含不可能。

**(5) 两条限制叠加会排除合法的定位。** 结构情形：层 2 的背驰段跨度为 `S`；层 1 在 `S` 之内尚无已完成段，能观察到的跨度只有 `S` 本身；层 0 在 `S` 内有真子跨度 `S′`。主谓词接受 `[(2,S),(0,S′)]`，也接受 `[(2,S),(1,S),(0,S′)]`。选项 B 两条都拒绝：前者不相邻，后者第一步不是真包含。有信息量的那条定位链恰好要靠跳层才能写出。

**(6) `[027:38]` 的收缩是理想情形。** `[027:38]` 「一定在季度线的背驰段里，而且区间比之小」讲的是逐级且真缩小，但 `[027:40]` 紧接着说这只是最理想的情况。所以把它留作对照谓词是恰当的：`StrictNestedDivChain` 蕴含 `NestedDivChain`，反之不然。

### 4.3 边界例

- `W17a`：顶层 `(2, [4,7])`，下层 `[(0, [4,7])]`。跳层、等跨度两点主谓词都允许；该例在乙方判假的第三个原因（层 0 的分解里没有 `[4,7]` 这个跨度）已由 `observedSpan` 统一挡住，与本轴无关。
- `W17b`：顶层没有背驰。已由顶层 `DivSegment` 统一挡住，与本轴无关。

### 4.4 对现稿的修改点

- `Chan/Defs/Dynamics/Divergence.lean:343-350`（`NestedDivChain`）与 `:352-358`（`StrictNestedDivChain`）：签名与实现不改，文档串改为定稿。
- 登记待证引理名：`nestedDivChain_of_strict`（字面档蕴含主谓词）、`nestedDivChain_erase`（删去任一非首项仍成立）。
- **一条不属本轴的提示**：主谓词与字面档都不要求各项共用右端点。`[027:44]` 的定位定理要用到“转折点落在每一层的跨度内”；在线读法下转折点是当下，所以定位类命题需要另加前提：各项的右端点都是当下。现稿 `checkedChain`（`:332-341`）允许下层跨度早于当下结束，这样的链是合法的套，但定位不到当下的转折点。建议 FM-4x 写定位命题时显式带上这条前提，或在冻结前加一条派生谓词。

## 五、`U-5`：M18 `WeakSafetySpec`（见证 `W23`）

### 5.1 裁定

**取选项 A。** 买点之后若出现同级中枢，其第三段在时刻 `m` 完成，则在 `(buy, m]` 之内有一个时刻价格不低于买入价。等价亦计，不计费用，买入时刻本身不算卖点。选项 B 保留为现稿的对照口径 `UnboundedWeakSafetySpec`。

硬证据：`[107:22]`、`[017:60]`（两条）、`[069:28]`。

背景旁证：`[二级旁证 108:178]` 「最恶劣情况下，最基本升幅已经达到」；`[二级旁证 105:442]` 「必须是可观察的」。

### 5.2 论证

**(1) 原文的卖点在上下上之内。** `[107:22]` 「后上的高点可能只刚好触及前上的低点」：在第一个上的最低点买入，等上下上都走完，最后一个上的高点至少触及买入价。这个卖点出现在第三段之内，不晚于它完成的时刻。其几何根据只是三段成枢：三段有公共重叠，所以第三段的高点不低于第一段的低点。`[017:60]` 「必须包含三个以上的次级别运动」给的是同一件事的另一半：后面至少还有一个向上的次级别运动。

**(2) 原文同时限定了强度。** `[107:22]` 「只有相对的理论上的绝对安全性，而没有具体操作上的绝对安全性」。选项 A 的结论是不低于买入价（含相等），正好是这个强度。

**(3) 选项 A 蕴含选项 B。** 对同一个 `buyNow`，A 给出的卖点落在 `(buy, m]` 内，自然也是买入之后的某个时刻。B 多判真的那些情形（`W23`：中枢形成期间价格全在买入价之下，中枢完成之后才涨回）靠的是与该中枢无关的后续行情，原文的论证不覆盖它们。

**(4) 可观测性上的分类。** 把规格的逐路径部分看成无限路径的性质。A 被违反时，有限前缀就能作证（到 `m` 为止没有回到买入价），所以 A 的否定是前缀可观测的，A 属于安全性一类。B 被违反意味着买入之后永远不回到买入价，任何有限前缀都不能作证，B 属于活性一类。这条规格在 B-24 的四分里叫弱安全性，另一条有界终结才是活性条款；把它写成活性命题，四条的分工就乱了。

**(5) B 的前件不起结构作用。** B 的结论与“形成同级中枢”没有时间上的联系，前件只是一个开关。A 的结论以该中枢的完成时刻为界，前件才真正进入命题。

### 5.3 边界例与一条收紧提示

- `W23`：`x = [10, 6, 8, 5, 7, 10, 10, …]`，时刻 0 买入，时刻 1 至 4 形成中枢 `[6, 7]`。A 判假，B 判真。

## 六、`U-6`：M19a `LivenessHyp`（见证 `W24`）

### 6.1 裁定

**取选项 C。** 对指定级别 `depth` 与统一步数界 `bound`：任一时刻之后的 `bound` 步之内，该级别的分解里各出现一段严格向上与一段严格向下的段。选项 A 与选项 B 都不作主假设。

硬证据：`[017:60]`（两条）、`[030:24]`、`[025:20]`。

### 6.2 论证

**(1) 这条假设是给有界终结用的，两样东西缺一不可。** `BoundedTerminationSpec`（`Chan/Defs/Limits/Liveness.lean:59-68`）要在 `n + bound` 之内给出指定级别对象的完成或升级。前提里必须同时有统一的步数界和该级别的成段事件。

**(2) 选项 A 缺级别。** 裸价格在每个定长窗里有涨有跌，不说明指定级别成了段；成段与否取决于级别规则与底层抽取器，幅度或根数不够的抖动可以永远不成更高一级的段。A 推不出某个级别上的任何完成。

**(3) 选项 B 缺统一界。** `W24` 的变周期路径（第 `k` 轮先平走 `k` 步）在层 0 上双向成段无穷多次，B 判真；但相邻两段之间的等待时间无界，对任何固定的 `bound` 都推不出有界终结。B 配的是“终将完成”，不是“有界完成”。

**(4) 选项 C 同时蕴含另外两个选项的内容。** C 给出的段两端价格严格不等，所以同一窗内裸价格也各有一次严格上行与下行；C 对每个起点都给出段，所以该级别双向成段无穷多次。`W24` 上 C 对每个 `bound` 都判假，与 A 一致，只是多了级别锚定。

**(5) 它是可违反的假设，不是规律。** `[025:20]` 「股票不断一字涨停」就是不满足的实例。`[017:60]` 的必然完成与 `[030:24]` 的交易延异性是这条假设的原文来源，按 B-37 只能写成显式前提。恒值路径、永久单边路径、`W24` 都违反它；逐步交替的路径满足它。

### 6.3 两条注记

1. **界是分级别的。** 高一级的段至少由三段低一级的段构成，同一条路径在不同层深需要不同的 `bound`。现稿的 `LivenessHyp` 以 `depth` 为参数，这是对的。`BoundedTerminationSpec` 却对所有 `depth` 共用一个 `bound`，用它时要由 `pending` 把对象限定在单一层深；否则应把 `bound` 改成层深的函数。本文只登记，不裁。
2. **C 能否推出有界终结仍是待证命题。** 本裁定只保证前提的形态足够（有级别、有统一界）；推出过程要用到九段升级封顶等 `#2320` 的结论，留给 FM-4x。

- `Chan/Hypotheses/Dynamics.lean:13-22`（`LivenessHyp`）：签名与实现不改，文档串把“暂行”改为定稿。

## 七、`U-7`：M19a `PullbackHyp`（见证 `W26`）

### 7.1 裁定

1. **取选项 B。** 区间之外，回复力指向区间，大小不小于一个正常数 `strength`。
2. **线性回复单列**为现稿的 `LinearPullbackHyp`，不进五项假设的打包结构。
3. **不取选项 C。** 参数化下界族对主线命题没有增量（7.2 节第 4 点）。
4. **连带对齐**：B-17 的条件命题 `DivReturnsToCenterStmt` 的结论改为越沿形态，与 `U-3` 一致。

硬证据：`[033:26]`（三条）、`[033:30]`、`[033:24]`（两条）、`[098:16]`、`[027:16]`。

### 7.2 论证

**(1) 选项 B 加推力预算，能推出有限步越沿，并给出显式期限。**

**命题。** 设 `PullbackHyp zone restore γ` 成立，残余推力 `r(t) = Δ²x(t) − restore(x(t+1))` 从 `s` 起向上的正部总和不超过 `B`（即现稿的 `ExhaustionHyp r .up s B`）。记 `a = s + 1`，`v_a = x(a) − x(a−1)`，`M` 为使 `x(a) − hi + m·(max(v_a, 0) + B) − γ·m(m+1)/2 ≤ 0` 成立的最小正整数 `m`。则存在 `t`，`a ≤ t ≤ a + M`，使 `x(t) ≤ hi`。

**证明。** 若 `x(a), …, x(a+m−1)` 都严格大于 `hi`，则对 `1 ≤ j ≤ m`，`v(a+j) = v_a + Σ_{i<j} (restore(x(a+i)) + r(s+i)) ≤ v_a + B − γ·j`。逐项相加得 `x(a+m) ≤ x(a) + m·(v_a + B) − γ·m(m+1)/2`。右端是 `m` 的开口向下的二次式，所以 `M` 存在；取 `m = M`，若前 `M` 个位置都在区间外，则 `x(a+M) ≤ hi`。证毕。

这个证明只用了回复假设与衰竭假设，没有用到惯性假设、活性假设与柱组假设。这本身是 M19b 红线第 3 条要求保留的“逐项剥离”信息。

**(2) 选项 A 推不出回拉，哪怕只要越沿。** 三个精确反例：

- **带误差项时区间外有平衡点。** 区间 `[0, 1]`，`κ = 1`，误差 `1`，取 `restore(p) = −(p − 1) + 1`（`p > 1`），下侧对称。它满足线性假设，而 `restore(2) = 0`。恒值路径 `x ≡ 2` 的残余推力恒为零，预算取零也成立，却永远停在区间外。
- **无误差项时可以无限逼近而不到达。** 上沿取 0，`restore(p) = −κ·p`。路径 `x(t) = 2^(−t)` 的残余推力为 `2^(−t−2) + κ·2^(−t−1)`，全程为正，总和恰为 `1/2 + κ`，二阶差分不超过 `1/4`。它满足线性假设、有限预算与惯性约束，却对每个 `t` 都有 `x(t) > 0`。整条路径乘以任意小的正数 `c`，预算随之缩成 `c·(1/2 + κ)`：再小的预算也挡不住。
- **有阻尼时零外力也到不了。** 研究库的推力模型里取 `ρ = 1/4`、`restoring(x) = −x/4`（`x > 0`）、外力恒零、`x_0 = 1`、`v_0 = 0`，轨道的闭式是 `x_t = (t+2)/2^(t+1)`、`v_t = −t/2^(t+1)`，恒为正。

所以线性回复下“有限推力预算必回拉”不成立；它成立与否要看别的量。它适合作研究库里的对照变体，不适合作主线前提。

**(3) 与原文的对应。** `[033:26]` 「都有相同的回拉作用」，`[033:30]` 「中枢B对这两段的回拉力度是一样的」。原文的论证是比较式的：同一个回拉，较弱的离开也被拉回。把回拉读成与离开方式无关的一个定量，这个比较论证才直接成立；一致正下界是支持它的最弱形式。回复函数本身仍是任意函数，没有限定成常数场，所以 `[033:24]` 的多中枢合力读法不受限制。

**(4) 为什么不取参数化下界族。** 设下界族由轮廓 `g` 给出，要求区间外距离 `d` 处回复强度不小于 `g(d)`。若 `g` 的下确界为正，它就是选项 B，`strength` 取该下确界，上面的命题原样适用。若 `g(d)` 在 `d` 趋于零时趋于零，取 `d_t` 递减且 `d_t ≤ 2^(−t)`、`g(d_t) ≤ 2^(−t)`，回复函数恰取 `−g`，则路径 `x(t) = hi + d_t` 的残余推力总和有限而永不越沿，与第 2 点的第二个反例同理。对 B-17 这条主线命题而言，轮廓里起作用的只有下确界是否为正这一件事，多出来的参数没有可证的内容。更细的轮廓放进研究库。

**(5) `W26` 两个方向的分离都保留。** 无噪声的线性回复不满足选项 B（靠近边界处回复强度小于任何正常数）；常数回复不满足 `κ = 1` 的无误差线性假设（远处强度不够）。两者不可比，所以是并列的两条假设，不是一强一弱。

### 7.3 三条必须写明的限制

1. **只有下界，没有上界，所以会过冲。** 选项 B 不限制回复力有多大。3.2 节第 4 点的周期轨道就满足选项 B（强度 4）与零推力预算，却永不落核。因此在五项假设下能证的是越沿，不是落核。现稿 `Chan/Hypotheses/Dynamics.lean:109` 的结论是落核形态；按该例的动力学部分，它在自己的前提下不成立（结构前件未在 Lean 中构造，见第十一节）。
2. **与作用范围有界不能同时假设。** 研究库的 `WellBoundedRange`（`ChanDyn/Well.lean:34-38`）要求超出半径后回复力为零；选项 B 要求区间外处处不小于正常数。两者对同一个回复函数联立无解。它们各自可满足、可违反，但任何同时以二者为前提的命题都是空真。建议在门禁或审计层登记这一对互斥前提。需要“逃逸边界”一类结论时，应另设带作用半径的变体，不要放宽主假设。
3. **研究库的落核型命题有显式反例。** `ChanDyn/Thrust.lean:37-43` 的 `ReturnUnderBudgetStmt`，取核 `[−1, 1]`、`rho = 1`、区间外回复力恒为 4（内向）、外力恒零、`position 0 = 2`、`velocity 0 = 0`、`budget = critical = 0`：三个前提都成立，而对任何期限 `BoundedReturn` 都不成立。它是待检命题，不构成不一致；这里只是把结果记下，供 FM-4x 少走弯路。

硬证据：`[033:34]`、`[033:26]`（三条）、`[033:30]`、`[015:42]`（两条）、`[024:14]`、`[024:22]`、`[024:24]`（两条）、`[072:34]`、`[104:16]`、`[104:26]`、`[061:28]`（两条）。

背景旁证：`[二级旁证 100:96]` 「并不是说MACD有什么特殊的地方」；`[二级旁证 029:328]` 「用MACD来辅助判断，效果至少95%以上」。

### 8.2 为什么现在不能定默认值

**(1) 三者两两反序，选哪个直接改变背驰谓词的真值。** `W9a`（`0→5→4→6` 对 `0→4→3→7`）：`L_break` 判后者更弱（`4 < 9/2`），冲量族各读数与 `L_avg` 都判不弱。`W9b`（`(0,0)→(1,4)` 对 `(0,0)→(1,4)→(9,3)→(10,8)`）：`L_avg` 判后者更弱（`4/5 < 4`），`L_break` 与冲量族都判更强。两组数字本文已用精确有理数复算，与对撞报告逐项一致。

**(2) 原文的两个代理读数分别对应两族，原文自己没有定一个。**

- 均线面积除以时间（`[015:42]`）在匀速段上是速度的常数倍（1.2 节第 5 点），是均速型的量，靠近选项 C。
- MACD 柱面积（`[024:22]`、`[024:24]`）是速度变化型的量：信号周期为 9 时，`dif − dea = 4·(dea(t) − dea(t−1))`，所以倍柱的带号面积精确等于 `8·(dea(e) − dea(s−1))`，是 `dea` 的端点差；`dea` 又是 `dif` 的平滑，`dif` 在匀速段上趋于速度的 7 倍，合起来就是引文包规范里的核常数 56。只读红柱（或绿柱）对应正变差读法。这靠近选项 A。
- `[024:14]` 「不绝对精确，但比较方便」：原文明说 MACD 只是辅助。`L_break` 在引文包内没有对应条目，它来自 `#2322` 评论 1 的外部参考。

**(3) 模型里的推力量是三个可观察量的组合，权重是模型参数。** 在研究库的推力模型（`ChanDyn/Thrust.lean:21-22`）里，设一段行情从 `a` 起共 `N` 步，其间位置都在上沿之外且回复力恰为 `−γ`，则逐步把速度更新式相加得到恒等式：

`Σ_{t=a..a+N−1} thrust(t) = (v(a+N) − v(a)) + (1 − ρ)·Σ_{t=a..a+N−1} v(t) + γ·N`。

三项依次是速度的端点差（冲量族的末态读数）、阻尼损耗（其中的速度和等于 `v(a)` 加上到第 `N−1` 步为止的位移）、对抗回拉所耗（与时长成正比）。模型 A 上取 `f = [8/3, 0]` 核对：`−5/3 + (1/2)·(2/3) + 2·2 = 8/3`。

把它用在两组见证上（上沿为 0，起点在沿上不计入区间外）：

| 路径 | 净推力 | 与对照路径之差 |
|---|---|---|
| `W9a` 的 `b` | `2 + 4(1−ρ) + 2γ` | |
| `W9a` 的 `c` | `4 + 3(1−ρ) + 2γ` | `1 + ρ`，恒正 |
| `W9b` 的 `b′` | `4` | |
| `W9b` 的 `c′` | `5 + 3(1−ρ) + 9γ` | `1 + 3(1−ρ) + 9γ`，恒正 |

对一切 `0 ≤ ρ ≤ 1`、`γ ≥ 0`，模型都判后一条路径耗力更多。也就是说：`W9a` 上 `L_break` 与模型反向，`W9b` 上 `L_avg` 与模型反向，冲量族在两组上都与模型同向。`L_avg` 把时长当作扣分项，而恒等式里时长是加分项，符号相反。

**(4) 但冲量族也不是模型序的忠实代表。** 取 `p = (0,0)→(5,5)`（五步每步速度 1）与 `q = (0,0)→(1,2)`（一步速度 2）。三个候选连同冲量族的两个读数都判 `q` 更强。模型的净推力是 `p：1 + 4(1−ρ) + 4γ`、`q：2`。取 `ρ = 1`：`γ = 1/8` 时 `p` 为 `3/2`，小于 `2`；`γ = 1/2` 时 `p` 为 `3`，大于 `2`。同一对路径的强弱随回拉强度翻转。因此**不存在与模型参数无关、又在整个参数域上与模型推力同序的力度读数**，三个候选都不例外。

**(5) 参数无关的比较只能是偏序。** 由于净推力对 `(1−ρ, γ)` 是仿射的，在 `[0,1] × [0,∞)` 上恒有 `T_c ≤ T_b`，当且仅当三条同时成立：区间外步数 `N_c ≤ N_b`；速度端点差 `Δv_c ≤ Δv_b`；速度端点差加速度和 `Δv_c + S_c ≤ Δv_b + S_b`。这给出一个可检的充分条件型的“弱于”，但它不是全序，两段常常不可比。

以上第 3 至 5 点是在回复力恰为常数的推力模型内的结论，是模型内的恒等式，不是关于市场的断言；`[104:16]` 与 `[104:26]` 也提醒过力度不该按牛顿式的算法照搬。它们的用处是说明：默认值这个问题在数学上依赖于 FM-42 要定的模型类，不能在冻结期用裁定代替证明。

### 8.3 为什么主攻口径取速度冲量族

1. 两组见证上，它是三者中唯一始终与模型净推力同向的（8.2 节第 3 点）。
2. 它是原文主要代理（MACD 柱面积）在结构层的对应物（8.2 节第 2 点）。
3. 它已经能用冻结后的 M16c 四参数表达：势取速度，读法取端点差或正变差，端点约定取自静止起算，求值都走现稿的 `readSamples`。`L_avg` 要另加时长归一，`L_break` 要另加按新开价域加权，都不是现有读法枚举里的读数，升为默认值须先改接口。
4. 它与 `[033:34]` 的抛球类比不冲突：`[033:34]` 「力度大的如果还抛不高，那怎么能算力度大」讲的是力度要在位置上兑现，这是对任何候选的检验条件（创新极值独立成前提，见 `[061:28]`），不单独支持哪一个候选。

主攻口径只是证明顺序上的安排，不是 Lean 里的默认值，也不预设结论：8.2 节第 4 点的例子对它同样是反例。
