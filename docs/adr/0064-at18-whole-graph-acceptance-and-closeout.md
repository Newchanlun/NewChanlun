# ADR 0064：AT-18 整图验收报告与关票门

> 正本：本文件是 #1323 AT-18 六项 Destination 逐项核验、TB-01..11 关票门、旧关联票去向与整图报告的正本。
> 最后裁定：#1551（2026-11-14，P 类，依 #1909 代理独审裁定）
> 受影响代码清单：本 ADR 不直接改代码；报告生成与独立总验归 #1391/#1403，TB-07 汇总归 #1366，AT-14 原件归 #1418。

## 一、范围与现状

本 ADR 只裁验收证据、报告结构和簿记，不交付运行证据，不提前关闭 #1279、TB-11 或任何实施票。

ADR 0063 的迁移协议合入不等于 #1368/#1402 的非空迁移、回退与恢复已经验收。ADR 0058 的 AT-14 仓内报告路径继续有效；新整图报告按现行仓外交付 manifest 管理，不将某台机器的绝对路径写成永久报告身份。

本 ADR 不签署真实资金、账户或场所激活、量档容量、成本/风险阈值及凭据权限；这些事项仍适用 ADR 0041 的独立用户授权硬门。

## 二、AT-18 逐项证据

每项 Destination 记录至少包含：Destination 编号与完整义务；实施票、范围与精确 commit；覆盖最终产品差异的非作者独评及所审 commit；实际 origin/main SHA 与适用 CI run；实体报告 artifact 路径、sha256 和射程；下游票状态与剩余义务；`PASS|FAIL` 结论。

组件证据、协议裁定、局部成功、正确拒绝、空域、仅 schema 或未执行测试均不得代替必需成功路径。缺证或射程不符即不得判 PASS。

## 三、TB-01..11 关票门

每个 TB 汇总记录至少包含：TB 编号与票号、全部内部实施子片、完整外部行为实际运行证据、最终独评、实际 main SHA、适用 CI run、实体报告、剩余义务与票状态。

关票要求票面验收全部满足，全部必需子片交付，评审覆盖最终产品差异，产品进入 origin/main，适用必需检查通过，实体报告可读并绑定版本，在制品已有合法处置。失败、未构造、未执行、权限阻塞及跨 TB 未闭合的联合义务必须保留为未完成。

## 四、旧关联票去向

- #1304：由 TB-07 完整历史回放、恢复、AsKnown、全状态对拍及 ADR 0058 AT-14 报告器承接；证据未齐前保持 open。
- #1319：既有 feed/wire 由 TB-08 核实收编，正式意图/回报归 TB-04，发送前隔离归 TB-09；旧简化链不得冒充完整程序。
- #1320：TB-07 承接正式完整回放；TB-11 另核 ES/GC/CL/ZN/6E/BRN/DX 各十年 1min、冻结预注册 7/7 测量与完整结果保留。组件有界测试不得销项。
- #1096：TB-10 实际勘察、TB-11 对账；冻结/收编登记与未来实际删除分别举证，删除仍须满足 ADR 0048 退场条件。
- #1279：保持 open 至 #1323 与自身就绪检查完整验收；AT-18 通过不自动关闭它，也不宣布试运行放行。

## 五、at18-report/1

整图报告由机器可读 JSON 和同源渲染的 `summary.md` 组成。新报告放仓外持久证据目录，由 delivery manifest 绑定 ticket、base、head、artifact 路径及 sha256；移动后更新 manifest 并重验。摘要不作独立判定。

JSON 至少包含：

- `schema_version`、`ticket`、`base`、`head`、`generated_at`；
- 恰好六项的 `destinations[]`；
- 恰好十一项的 `tb_summaries[]`；
- `legacy_dispositions[]`，覆盖 #1096、#1304、#1319、#1320、#1279；
- `unexecuted[]`，每项含义务、原因、阻塞票或缺口及是否必需；
- `failed_checks[]`、`permission_blocked[]`、`bounded_domain_statement`；
- `overall_result: PASS|FAIL`。

`overall_result=PASS` 当且仅当六 Destination 全部 PASS、十一 TB 均满足关票门、四张旧工作线均有核实的合法终态或真实承接、#1279 剩余义务如实列出，且所有必需未执行项、未处置失败和权限阻塞均为空。

TB-11 关票评论须写报告 artifact 路径与 sha256、实际 main SHA、适用 CI run、最终独评、未执行项及旧票去向；无实体报告即写「无报告」，不得声明整图通过。

## 六、实施归属与图边

#1391 负责逐项对账，#1403 负责确切提交和完整运行包的独立总验。#1366 负责 TB-07 汇总，#1381/#1399/#1411 分别保留完整回放、seek/修订重算、双进程崩溃恢复的既有实施义务；#1418 继续交付 AT-14 原件。本 ADR 不新增或删除 blocking 边，不改变 TB 原 DAG，不把旧关联票整票设为 TB-11 新前置。
