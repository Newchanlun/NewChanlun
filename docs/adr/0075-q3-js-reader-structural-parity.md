## 裁定：选 A，由公开入口独立拒绝

`Q3.validateState(state, "s-session/3")` 必须按下列同一套谓词验已发布原件。JSON 对象和 Q3 Client 的图值共用入口；错误、缺证、超限均不得安装，不向 Rust 查询补判、不退回弱验、不增加宽严配置。Rust S 仍是唯一结构计算者，Rust S/Q 仍负责发布与一致捕获审计。这里的「对等」限于本 ADR 列出的、能从被交付的 S3 原件独立核验的关系、事件、请求、来源和目录；客户端不签发出生许可，不重造分类、包含、分型、线段、中枢或中枢对，不扩为 Rust 私有库全审计。

依据是 SPEC 阅读版 [C02.2 :254](../../.chanlun/review-results/issue1339-r2-spec-20260909/view/spec/SPEC.md#L254) 的唯一结构核与 [C08.1 :312](../../.chanlun/review-results/issue1339-r2-spec-20260909/view/spec/SPEC.md#L312) 的不补判，[签署原稿](../../.chanlun/review-results/issue1339-r2-spec-20260909/payload/spec/SPEC.md) :252/:310 同文；[S README :171](../../s_session/README.md#L171) 明写只读已封存事实，[ADR 0037 :12–16、:37–45](0037-s-content-bounded-layout.md#L37-L45) 保留布局版本分派和 31P 单元源边。[#1394 采纳件 §5.6–5.6.1](../../.chanlun/review-results/issue1394-content-v3-20260916/APPROVED-SOURCE.md#L280-L309) 区分范围证明与正文/来源校验，并要求完整验证、累计计费后才安装。`structure-classification/1` 是请求地址；从已记录的向量、枚举、空值或 SECOND 扫描证据核请求四轴，和从行情重编结构是两件事。

## 为什么不选 B 或 C

**B：只信正式写者与 Q。** 对确实走正式 Rust Q 的成功响应，S 是事实生产者，Q 是独立读侧守门者，不是页面或 caller 自行证明：三路 Snapshot/Content/Watch 在 [`q_runtime.rs` :296–313、:573–603](../../rust/src/bin/s_session_v3/q_runtime.rs#L573-L603) 经 `AuditReader.with_capture`；[`capture.rs` :91–103、:1406–1466、:1627–1704](../../rust/src/bin/s_session_v3/capture.rs#L1406-L1466) 只在一致镜像实际 state audit 成功后提供不可变已核捕获，缓存复用仍受源版本、捕获身份与资源门约束。对应锁见 `q_runtime.rs:1189,1480,1570`（实际捕获、TCP 三路与 ready 原账），`capture.rs:2615`（变源/损坏缓存隔离）及 `state.rs:2881,2899,2917`（坏根、坏原始来源、坏目录拒绝）。这些是基线源码和已接用例的位置，不是本轮重跑结果。

页面 [`index.html` :713–788](../../s_session/browser/index.html#L713-L788) 用显式资源/分配适配器经 `Client.loadReady/watch`；[`q3-consumer.js` :2083–2133、:2528–2591、:3017–3052](../../s_session/browser/q3-consumer.js#L2528-L2591) 核固定切面、证明、正文、Watch 同代对拍并原子安装。:1464 直接用的是 S2；:1477–1479 有 S3 分派分支，正常 S3 页面读取通过 Client。根和对拍不能给自备 JSON 生成 Rust 审计来源；`Q3.Client` 还允许注入 fetch，任意第三方响应不因使用 Client 就成正式 Q。[`tb01c-client.js` :8923–8929、:8943–8950](../../s_session/browser/tb01c-client.js#L8923-L8950) 同时导出 CommonJS 和浏览器 API；[`test_q3_s3_center_contract.cjs` :789–855、:1187–1281](../../s_session/tests/test_q3_s3_center_contract.cjs#L1187-L1281) 和 [`test_q3_v3_validate_once.cjs` :40–45、:70–112](../../s_session/tests/test_q3_v3_validate_once.cjs#L70-L112) 已直接传入 State。B 的好处是省 JS 维护和读预算，代价是导出 API 对 27 个已复现坏状态和 8 个新目录负控仍放行；离线及第三方无法获得本票要求的独立判断。A 也不把一致性校验说成来源认证。

**C：其余做独立校验，B4 留给 Rust。** 真实历史上的 B4 确有额外遍历，但不需逐代全量重建。基线对应 [真实切面 t1–t5](../../s_session/tests/test_q3_s3_real_cut.cjs#L141-L202) 的真实 Rust W1 导出（7 个里程碑，含恢复、两次修订和尾段中枢对）。本机 Node 22.23.1 在真实行/字段投影上测当前索引、请求和来源走访，以及历史逐代重建 vs 事件增删；跑前装载夹具，预热 10 次，取 41 次 p95。g106 活动 689、累计撤回 3345、历史 typed 关系版本 224；历史全扫约 42.8 万行次，事件增删 7379 次、两臂仍同为 1733 次链接/事件访问。g106 热态 p95：当前 B2/B3/B7/B8 与目录索引约 1.190 ms，B4 全扫 7.133 ms、事件扫描 1.769 ms；从本地已载图提取该代字段另测 1269.296 ms（共享缓存一次样本，不是增量实现开销）。读数、脚本和逐案对照见 #2072 R1 复核原件。

t1 只对规则，无读作业。t2 原有 g1/g2 作业为 15.364/17.387 s；t3/t4/t5 作业峰值分别为 604.197/2261.194/2875.838 s（[冻结回执](../../.chanlun/review-results/issue1419-q3-real-cut-receipts/README.md)）。共享试验配置为单请求 30 s、累计作业 60 s，不是生产默认；t3–t5 的最重作业原本就超 60 s，不能归因于新增 B4。该真实切面套件专用 4 h 作业期限，峰值作业原余 11524.162 s。这些数只支持把 B4 纳入并做索引化实装，不替代改码后同配置的 Reader/Watch 期限与记录、暂存开销验收，也不外推到全 9011 代。保留 B4 只在 Rust 会留下已被撤回的坏关系；现有数据没有支持这种范围削减。

A 的代价是跨语言谓词需要一起维护、额外索引与计费。只解码一次所需字段，按事件扫或维护依赖反索引，在同一个 `check/charge` 下核验；`max_elapsed_ms`、记录及暂存预算不提高，失败仍保留旧 committed cut/cursor。B、C 是比较过的职责划分，不是可配置的松档（#799 / #804）；算法可省重复检查，不能换判据。

## 阶段二验收与依赖

1. 先用原件在冻结基线得到 **34 组 = 2 接受正控 + 27 错受目标 + 5 正确拒绝**。改码后用公开 S3 入口拒绝目标 27（B2/3/4/7/8 = 6/2/2/11/6），原 5 仍拒、原 2 仍过；新 8 个目录负控全拒（3 个独立计数，及 CC-056 撤回省略、重复、原因、替代 ID、槽，各自在真实 W1 正控上改、复制面同步）。反例要命中相应义务；保留单谓词对拍证明，避免全部被其他更早的计数门先挡就算完成。W1 正控是真实原件；W2 正控是依 W2 重绑的同底座，不当作 W2 写者端到端。
2. 加可分辨的历史正/负对：出生时绑定合法、后续仅端点/见证换版或撤回且边仍在世必须拒；同代换边、换端与合法旧 AsKnown 继续过。目录测试同时覆盖 typed 与 shape 撤回、原序/替代配对；保留 cut0、历史规则与 31P 鉴别锁。用同一谓词测图值和普通 JSON，并验 Client 在负控及接近绝对期限/超记录上限时不安装、不推进，不使缓存命中免计费。
3. 由测试目录的 [`build_tb01c_browser.cjs` :6–17、:39–45](../../s_session/tests/build_tb01c_browser.cjs#L39-L45) 用 `--write` 重建 bundle、`--check` 验无漂移，不手改生成段。复跑 `s-observer` 的 validate-once、S3 合同、t1/t2；bundle 变化时按 [CI :1400–1428](../../.github/workflows/ci.yml#L1400-L1428) 在重型窗口逐条重跑 t3–t5 并更新真实收据，保留原冻结额度和分流。报告基线/候选同切面的新增时间、访问量与实际剩余预算。上限确实不足时按已有 Incomplete 处置，先优化同一谓词再交付，不少验历史。
