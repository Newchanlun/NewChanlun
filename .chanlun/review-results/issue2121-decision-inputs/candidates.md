# 候选与取舍

## Q1：估计量与方法族

| 候选 | 估计对象与可比性 | 处置 |
|---|---|---|
| 合并抽中月块的所有事件，取中位数，再取其 bootstrap 下分位 | 典型一趟完整往返；极少数大幅个例不能任意抬高典型量。#907 实际用中位数作典型读数，并提出补中位数区间（报告 :139–147、:294）；#915 明写沿用且区间仍缺（报告 :363、:407）。 | 默认。新裁，不把 #907 点估计升级为证据。代价：不是期望毛收益，不直接量化少数大幅交易的贡献或亏损频率。 |
| 同样重采样，取全部事件算术均值（合并波幅总和／合并事件数） | 每趟期望毛波幅；35 课的「平均」未给统计定义。#907 报告均值／中位数 2.12–2.91；大幅尾部可抬高整个块被抽到时的均值。 | 保留为另立版本的研究选择；本次以有往返中位数—区间先例的典型居中目标为默认，不以给定 θ 下谁过线多决定。 |
| 每月均值再等权平均；每月中位数再取中位／均值 | 典型月份；稀疏月与密集月一样重，改变一次往返的统计单位。适合研究月度稳定性，不等于全事件均值或中位数。 | 不作当前事件口径的算法替代；可单报诊断，不作为另一通过通道。 |
| 合并总价格差／总入场价；按量、持有时间或月数加权；波幅总和 | 总价差比是按入场价加权的收益率；业绩、暴露或吞吐是不同目标。纯总和的尺度正比于交易数，不是可与单趟成本比较的波幅。 | 不作当前门的估计量；若所谓「总和比」只是 `Σppb/Σn`，就是事件均值，不立第三种。 |
| 截尾／缩尾均值、几何均值 | 截尾／缩尾需预先规定阈值，可能抹掉真正小幅往返；几何均值关注乘法风险或对数，零幅使对数口径退化。 | 保留稳健收益、复合风险的研究问题；未裁修整比例、模型与零值口径，不授生产 method_id。 |
| 原样本 p5/p10/p25、原样本均值或 p50 直接作 A | 点估计或原分布分位数，不是估计量的置信下界。#907 :173–219 的中位／下尾结论可相反，原表没有区间。 | 排除作门；可作报告。对下尾分位数**另做**月块置信下界则是另一估计目标（保尾部而非保典型），不作为本版可切换宽严档。 |
| 窗内月块统计量最小值；iid 次序统计量精确区间、正态 LCB | 块最小值不是全事件中位数的置信界，极稀疏月可支配窗；iid 区间不能保护簇依赖；正态近似有分布假设，#853 的覆盖问题针对另外一个量。 | 都不替代 ADR 0035 已定的时间块 bootstrap；不在失败时重判。 |
| 校偏 BCa／学生化区间等块重采样变种 | 要额外定义加速度、方差估计、退化分布处置与样本前件；可能改善覆盖，但仓内没有这类波幅证据。 | 非本票默认；列未决研究，不事后选对自己有利的区间。 |

均值与中位数不是固定宽严关系：把任一个向量原样复制到每一月，则每次重采样仍给同一统计量。`[1,1,100]` 的均值为 34、中位数为 1；`[0,8,8]` 的均值为 16/3、中位数为 8。两者各自能比对方更难过线；区别是估计目标，而非以一者兜底另一者。没有根据把这两个 estimand 下的同一个真实 θ 当成授权等价。

## Q2–Q6：每项参数、边界、版本

| 项 | 采用与依据 | 未采用／代价 |
|---|---|---|

| PRNG | 新裁 PCG-XSH-RR 64/32 set-sequence，补足 ADR 0035:34 名称未表达的状态初始化与输出语义；便于共享精确测试向量。 | 现有回测 `metrics.rs:731` 的 SplitMix64 服务 PnL 总量，不把其读数与 A_ℓ 混用；可研究更换生成器，必须新版本，不能无声替换。 |

| 置信分位 | ADR 0022 裁定三/记录化 §1 固定取 `1-confidence`；该项读取继承门版本。新裁选经验逆 CDF：第 `ceil(B(1-confidence))` 项、不插值，借 :34 的先例。 | #907 的 `q(n−1)` 插值用于描述性原样本，v1 秩处插值可能把下界抬高。不同分位估法是独立方法，不能以同 id 替换。 |

| 逐窗或合并 | A 类，沿 ADR 0022 裁定七及 #1441 的 #1677 等同；逐层逐窗先验资格，全窗各自过线。 | 全史合并、平均下界、多数窗通过会掩盖短板；合格窗的最小值在同 C、同 θ 下可展示，但不能取代各窗原读数与资格。 |

## 未决与承接

- **是否另立均值、稳健截尾或校偏版本**：目前没有在同一批合格原件上、按预登记目标验证个别替代法适用性的证据；尤其没有能证明现有真实 θ 对不同 estimand 授权等价的材料。默认只裁「典型往返」方法。替代估计目标、区间的真实覆盖优劣及合适的更长块跨度未决，不给生产备用值。
- **跨月长持有与时间相关性**：月块保留同月依赖，不等于证明跨月独立；#907 L4 的 486 天中位持有是风险线索。真实研究须标注适用前提、查同一数据的有效块／截窗及覆盖表现；已裁证据门和 #1441 原验收不可豁免。本次不以未知的真实覆盖率阻塞纯确定性方法定义，不宣称联合 95% 覆盖或任何已验证市场结果。
- **实施事实**：#1441 按登记原件产出真实数据集身份、窗口表及往返样本并完成独评／公用入口验收；去重身份、同 bar 合法性及样本源验证不得因更名被跳过。本票不补造样本、不改数据源、同 bar 规约或场所成本；TB-08 提供来源与签署版本，TB-07 消费 AsKnown。#2111 已独审 PASS，正式合入依它的原流程，不把本票当作其合入证据。
