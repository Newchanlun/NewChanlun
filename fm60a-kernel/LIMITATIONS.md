## 一、`check.py` 机检管不了的部分（必须靠非作者人审）

`fm60a-kernel/check.py` 只能检查**结构与算术不变式**（逐字切片、准入表重算、禁止非作者入 `refs`、封闭语气枚举、条件句 `antecedent` 非空、作者陈述层阿拉伯数值与 `LV*` 逐字回溯、高风险未引限定词拦截、建模层必指 `AS*`、实例 `data` 全部数值在 `literal_bindings` 与 `free_parameters` 间不重不漏、反事实 `author` 必指 `假设或反事实` 语气、条件求值为真）。以下五类语义忠实性问题**无法机检，必须靠非作者人审**：

1. **转写忠实性**：`author_statements[*].statement` 与 `antecedent` 是否在未触发数值/禁用词拦截的前提下，隐蔽地增删了范围限定、因果关系或时态（例如把未定写成已知）。
2. **语气归类准确性**：`mood` 的 7 项取值（`直陈事实` / `条件句` / `假设或反事实` / `预测` / `事后回顾` / `设问或留作作业` / `引述他人`）是否判对，特别是反问修辞（如 `081:36`）vs 真实留作作业（如 `054:58`）、当日回顾更正（如 `081:30`）vs 即时陈述。
3. **`binds_instance_target_literally` 标注准确性**：作者原文给出了数字，但该数字究竟是不是字面绑定到某一具体对象或字段（如 `057:32` 的 `[4087,4122]` 仅绑区间标量而非顶点、`081:30` 的 `5386.39` 未指明高点或低点故标 `false`），只能靠人审原句确认。
4. **建模前提完整性与并列读法覆盖度**：`organizer_models[*].added_premises` 是否漏列了隐含前提（如成核规则、方向奇偶、无前置包含假设），以及同一条作者陈述是否还有本批未列出的合理并列读法。
5. **反事实预期是否超推**：`expected_under_instance`（尤其是 `counterfactual_proposer="organizer"` 的对照实验）是否仅主张了在所列前提下真正推出的最小结论，而没有把「否定一项充分证据」夸大为「否定命题本身」。

1. **分类边界上的可争论条目**（61 条中分类计数 `3 / 27 / 26 / 5` 不变）：
