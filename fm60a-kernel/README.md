# FM-60a 内核判例数字化（#2324，R2 三层格式）

本目录交付对 #2324「FM-60a 原典判例数字化」的四分类判断与 R2 修订后的三层结构化内核判例产物（`fm60a-kernel-v2`）：将 61 条原典判例按「是否依赖当年 K 线」做四分划（`3 / 27 / 26 / 5`），按新三层格式（作者陈述层 / 整理者建模层 / 合成实例层）重做 **9 条重点示范判例**，并将未审查的其余 20 条旧格式记录原封不动隔离。

引文括号约定：`【归属 课号:行号】「…」` 为缠师逐字；`『…』` 为网友或编者；`〈…〉` 为概括。

## 目录内容
