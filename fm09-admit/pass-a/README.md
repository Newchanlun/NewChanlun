## 对规格的读法（有歧义处取最保守）

1. **摘句之外的注不影响判定。** 规格问的是「`quote` 在原行里占哪些字符中哪些是作者文字」。摘句紧邻编者注、但本身不含注的（例如 id 265 在「（注：3买卖点后…）」之前截止，id 5、18、20、31、98、109、190、224、250、251、254、255、395、400、401、678、714、732、755、758、969、1028、1029、1031、1061、1063、1142、1286、1364、1440、1457 等），判 `clean`。
2. **作者自称与自命名算作者文字。** 「本ID」「缠中说禅买点定律」「缠中说禅走势中枢」「缠中说禅板块强弱指标」等是作者给自己理论命名的固定说法，不属于「以第三人称称呼作者的括注」。正文区中以第三人称称呼作者的只出现在摘句之外的注里（「禅师」「缠师」等），没有落进任何摘句。
3. **作者自引不算他人原话。** 作者在后文引用自己前课原句（如 1156 引第 67 课原句），算作者文字。
4. **作者的引号术语不算转引。** 「“吻”」「“不患”」「“下跌+盘整”」「“早泄”」等是作者的强调或术语用法，不是引用他人原话。1000 中「有位叫袖手旁观的网友理解得也不错，……」是作者转述并评论网友观点，没有引号、是作者行文，判 `clean`。
5. **无注字头的括注逐条看措辞。** 以作者口吻写成的括注（「（注意，……）」「（为什么？……）」「（严格来说，……）」「（这从黄白线就一目了然了）」，以及包含「本ID」的括注）判作者文字；措辞是标签式、事后视角或配图提示的，判编者注或按拿不准处理（见上表）。
6. **列举序号、算式、区间记号**（「一、」「2、」「[ZD，ZG]」「（1，0）」）是作者行文的一部分。
7. **摘句起止不完整不影响作者归属。** 例如 397 从「18。5」的「5」截起、902 从句中截起、1503 以逗号开头，都只是截取位置问题，字符本身是作者文字，判 `clean`；本步骤不评价摘句截取是否得当。
8. **`trimmed` 的区间修边。** 剔除编者注后，各段首尾的空白（半角/全角空格、NBSP、制表符）不计入作者区间；标点保留。因此 760、1259 剔除括注后，括注之后作者原有的句号单独成一段。
9. **`nonauthor_kind` 在 `clean` 时写 `none`。** 自检同时要求 `clean ⇔ none`。
10. **摘句定位。** 先整串精确匹配（NBSP 与空格视为同一字符，长度不变）；失败才按省略号切段依次匹配。全部 790 条都是整串命中。

## 文件与脚本

- `tier1.jsonl`：交付物，790 行，键序按规格。
- `decisions/bNN.json`：逐批人工判定（`clean` 的 id 列表、非 clean 条目的剔除子串与理由、拿不准清单），`tier1.jsonl` 由它们机械生成。
- `tools/common.py`：读台账正文条目、读原行、定位摘句区间、算 sha256。只用当前检出的 `docs/chanlun/text/blog/`，未导入 `fm09-register/tmp/lib.py` 的注识别或人工非作者清单。
- `tools/view.py`：阅读器。按课号排序、按窗口字符量分批（预算 8000 字），打印目标行 ±3 行全文，摘句以 ⟦⟧ 标出并附机械提示。提示只用来提醒，判定都是读原行后人工写进 `decisions/`。
- `tools/todo.py`：列出某批中还没有判定的 id，保证全部读到。
- `tools/build.py`：把 `decisions/` 合成 `tier1.jsonl`；对 trimmed 条目，从摘句区间里剔除指定子串，再做首尾空白修边。
- `tools/hints.py`：复查用，列出摘句内含括注、引号、「缠中说禅」「网友」等记号的条目；交卷前据此对所有命中条目逐条复核了一遍，判定没有改变。
- `tools/selfcheck.py`：规格自检全部项目（行数与 id 序列、区间合法与包含、verdict 与区间一致、sha256 可重算、1259 非 clean、265 为 clean），另外核对语料指纹（按文件名排序后逐个 `sha256sum` 行拼接，再取 sha256，结果等于规格给出的 `b6a35574…`）和台账行数 1604。
