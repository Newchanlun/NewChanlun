## 4. 规格边界与保守读法说明

1. **行内非作者括注的边界与周边标点**：仅剔除非作者括注本身及唯一服务于该插注的前置粘连空格（`id=778` 中插在中文与 ASCII 左括号之间的单个 `\u00a0`）；保留括注两侧的作者原句与句末标点（如 `id=1259` 保留 `[126, 127]` 的 `。`、`id=778` 保留 `[24, 25]` 的 `。`），使 `author_spans` 拼接后保持作者原句完整。
2. **转引他人原话（`quoted_other`）的界定**：
   - 出现明确引号转引古人/网友/他人原句时，剔除引号及其内原话，保留引号外作者自述（`id=132` 保留“……正如《论语》所说”，剔除截断的 `“由诲女，知之乎！`）。
   - 作者自创术语、特殊强调引号（如 `“早泄”`、`“吻”`、`“不患”`、`“走势终完美”`、泛指哲学套语 `“一分为二”`）、作者自引前课或作业题（如 `id=199`、`id=1066`、`id=1156`），以及无引号的作者间接转述（如 `id=1000` `064:26` 中“有位叫袖手旁观的网友理解得也不错，线段必须要被破坏才算结束，但必须要强调的是……”系作者用自己语言概括并延伸的理论命题而非逐字原话），均判定为作者文字（`clean`）。
3. **无“注/娇”前缀括注的甄别**：不靠前缀关键词或括号形态一刀切，逐条结合语义语体、上下文同类记号（如 `049:20/22/24` 三连项、`046:18/26/28` 与 `L20/22/24` 对照、`058:26/30` 同课编者风格）并辅以独立编纂版 `docs/chanlun/text/chan99/` 核对；凡作者确系自注者（如 `047:30` `id=760`“（请看下图）”在 `chan99` 原文完好保留，`049:30` `id=781`、`056:60/64`、`058:26`、`060:44/50`、`064:34`、`065:40`、`068:26`、`086:70`、`088:54`、`091:28` 等）均留作 `clean`。
4. **无 `↑正文` 分界标记的课文**：台账正文区涉及 9 篇无 `↑正文` 标记的课文（`000`、`001`、`002`、`003`、`004`、`005`、`006`、`046`、`085`），均打开完整原文文件核对正文与解盘/回复/附录边界，确认所涉条目均在缠中说禅正文范围内。
