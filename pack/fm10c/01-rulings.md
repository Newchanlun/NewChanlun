# FM-10c 裁定与修复口径（M0 至 M9 与 M15）

本文件汇集声明包甲（`#2320`，模块 M0 至 M9 与 M15）盲写阶段必须遵守的顶层裁定、清单 B 修复处置、FM-10a（`#2318`）原型实测结论以及 `#2316` 引文规则。

## 一、`#2295` 七项顶层裁定（全部锁定）

1. **决策 0（总定位 = 乙，原典考据加严格数学修复）**：主线 `Chan/Defs` 交付公理自洽、边界闭合的严格修复版定义；原典笔误或矛盾处不强行圆场，主线明确修复并留待 `Chan/Audit/Literal` 对照。
2. **分叉 1（级别升高规则 = 丙）**：级别规则抽象为统一接口，`规范进位（九段）`、`同级别分解`、`中枢延伸无上限` 均作为显式实例实现。
3. **分叉 2（C 类预测与盈利断言 = 甲）**：不得使用公理；本包形态学层不混入预测或盈利承诺。
4. **分叉 3（力度与动力学本质）**：本包 M15 第一类买卖点等涉及力度的位置，通过抽象力度/背驰条件参数接入，不得硬编码 MACD 或均线指标，不得导入 `Chan/Proxy`。
5. **分叉 4（离散价格等号口径 = 甲）**：全包统一一条规则：闭区间相交即算重叠（单点相触算重叠），离开与第三类事件必须严格越过（端点相触不算离开、不算第三类买卖点）。与原文字面 `020:60` 冲突处显式按 `054:24` 统一。
6. **分叉 5（纯数学包边界 = 甲）**：只交付纯数学抽象定义，不含账户、风控、IO 或 Rust 扫描逻辑，不参考冻结的旧 `formal/` 或 `.chanlun/definitions/`。
7. **分叉 6（动力学深度）**：不在本包定义，归声明包丙（`#2322`）。

## 四、来自 FM-10a（`#2318`）的实测结论（M6、M7 必须吸收）

1. **M6 规范分解唯一性的前提修正**：`#2318` 已在内核证明，仅靠"接口律加进位有界律"不足以推出分解唯一性（八段来回序列上 `3+5` 与 `5+3` 两种合法分解并存），且去掉进位有界后仍可存在唯一分解。因此 M6 规则接口除保留接口律与进位有界律外，必须独立刻画**起点定终点加尾部穷尽**（或等效的局部确定性规范谓词）作为唯一性前提。
2. **分解判同标准**：同一序列、同一规则下，两份分解相等当且仅当**各级原始切点下标表相等**。方向与实际值域是导出量；证明证书不得进入判同（同一切点表可带多种证书）。
3. **上一级粗化项必须保留实际值域**：仅保留端点或核不足以决定后续相对位置，粗化后的上级段必须保留完整闭区间值域（即所辖下级段值域的凸包）。
4. **M7 规范进位三处原文未定分支须显式参数化**（待 `#2296` 冻结时拍定默认值）：
   - 分支 A：九段之前块何时算完成（核被破坏才完成 vs 三段重叠即成块）；
   - 分支 B：九段按 `3+3+3` 进位之后如何重新起核；
   - 分支 C：成核三段是否可包含块首段、是否要求独立进入段。
