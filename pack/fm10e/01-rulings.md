# FM-10e 裁定与修复口径（M16、M17、M18、M19a 与 M19b）

本文件汇集声明包丙（`#2322`，模块 M16a、M16b、M16c、M17、M18、M19a 及 M19b 模型类签名）盲写阶段必须遵守的顶层裁定、`#2322` 评论 1 的三处订正、M19b 五项红线、清单 B 修复处置以及 `#2316` 引文规则。

## 一、`#2295` 七项顶层裁定（全部锁定）

1. **决策 0（总定位 = 乙）**：主线交付公理自洽、边界闭合的严格修复版定义；原典循环陈述（如事后才算数的背驰）与不可无条件成立的断言全部拆清。
2. **分叉 1（级别升高规则 = 丙）**：背驰、区间套与无限活性定义显式接收级别规则与分解参数，不写死单一规则。
3. **分叉 2（C 类预测与盈利断言 = 甲）**：禁用 `axiom`；所有动力学前提必须写成取值为 `Prop` 的显式命名假设；主线动力学命题只保留可检验的回拉与弱安全性结构，不命名为"背驰必转折"。
4. **分叉 3（力度与动力学本质）**：追求动力学本质，MACD 与均线面积只归入代理层 `Chan/Proxy/`，绝不进入 `Chan/Defs/` 核心依赖；结构内蕴力度与三分量接口归 `Chan/Defs/Dynamics/`，四参数与五假设均不设默认值。
5. **分叉 4（离散价格等号口径 = 甲）**：创新高/新低与严格分离使用严格不等号；背驰比较中力度相等（不大于）是否算背驰按 `[二级旁证 051:246]` 与严格小于并立明确写清。
6. **分叉 5（纯数学包边界 = 甲）**：只用有理数/有序域与有限和（`Finset.sum`），测度论不进可信核（`029:328` 仅标猜想）。
7. **分叉 6（动力学深度）**：在独立研究库 `ChanDyn/` 下建立第 33 课中枢回拉模型 D1 至 D4 的模型类签名（D0 归 `Chan/Audit/Math`）；`Chan/Final` 与 `Chan/Defs` 绝不导入 `ChanDyn`。

## 二、`#2322` 评论 1 三处订正与防泄题边界（必须遵守）

1. **零轴回拉界订正（M16a）**：仅假设最近 `n` 根（`n >= 9`）落在宽度 `R` 的价格带内不足以得到只含 `R` 的界（旧价恒为 100、最近 9 根恒为 101 时带宽 `R = 0` 而 `DIF` 非零）。正确表述必须引入更早价格到新价格带的最大距离 `delta`：`|DIF| <= A * R + (q_26^n - q_12^n) * delta`，其中精确有理常数 `q_12 = 11/13`、`q_26 = 25/27`、`A = (25/27)^9 - (11/13)^9`（不写四位小数近似），且此界只针对 `DIF`，`DEA` 需使用卷积后的核单独表述。
2. **均线面积出处核正（M16a）**：均线"面积除以时间"的权威出处为 `015:42`（准入表 `admit_id=71, 72`）。
3. **对称单峰与平移不变性落点订正（M16a、M16c、M19a）**："对称单峰时到峰面积乘 2 精确等于全组面积"对柱组 `1, 2, 1` 不成立（全组 4，到峰含峰 3，翻倍 6），相关假设必须精确区分是否半计峰值点或采用连续对称模型；**价格平移不变性必须挂在读数（Reading）上，不得强加于所有势函数（Potential）**，否则会排除均线面积实例。
4. **防泄题声明**：本引文包严格不含任何外部对撞专用候选定义式；M16b 结构冲量族与 M16c 四参数接口一律**不设默认值**。

## 三、M19b（`ChanDyn/`）五项红线

1. 禁用 `axiom`，全部假设写成取值为 `Prop` 的定义或结构字段。
2. 每个假设结构预留独立可满足与可违反的判定形态。
3. 每条条件结论接口保留逐个剥离假设与背驰前提的结构位置。
4. 假设的依赖闭包不得包含结论谓词（如"回拉"），供门禁 14 机械检查。
5. `Chan/Final` 与 `Chan/Defs/` 严禁引用 `ChanDyn/`。

## 四、`#2316` 结项引文规则

1. 硬证据只取 `02-citations.md` 第一部分（`#2317` 790 条正文区准入表）。
2. 二级旁证只取 `02-citations.md` 第二部分，文档串必须显式标注 `[二级旁证 课号:行号]`，且不得引入任何行内编者注（如 `105:518` 娇注已剥离）。
3. 禁止引用旧登记册主册、总计划手册或旧 `formal/`。
