# FM-10e 节点非形式规范（M16、M17、M18、M19a 与 M19b 模型类签名）

本文件只给出 M16a、M16b、M16c、M17、M18、M19a 与 M19b 模型类签名的非形式数学规范与接口要求，不包含任何 Lean 类型签名或外部对撞候选公式。全包在有序域（如有理数或抽象线性有序域）与有限时间索引上建立纯数学、精确有理、无公理的定义。

## M16a 精确核代理层（`Chan/Proxy/Ema`、`Chan/Proxy/Macd`、`Chan/Proxy/MaArea`）

注：本模块归 `Chan/Proxy/`，不属于 `Chan/Defs/`，只定义可精确代数计算的代理读数，不进主线形态学或核心力度定义依赖。

- **指数均线与简单均线（`Proxy/Ema`）**：
  - 给定平滑系数 `alpha`（有理参数，如标准周期 `N` 对应 `alpha = 2 / (N + 1)`，从而衰减因子 `q_N = (N - 1) / (N + 1)`）与初始播种方式（如首值播种 `x_0` 或显式给定初值），递推定义指数移动平均 `ema`；并定义窗口宽度 `N` 的简单移动平均 `sma`。
  - 保留精确核权重与滞后窗口参数，支持用精确有理式表述零轴回拉界所需的历史距离项 `delta`（`|DIF| <= A * R + (q_26^n - q_12^n) * delta`，`A = (25/27)^9 - (11/13)^9`）。
- **MACD 三件与柱组读法（`Proxy/Macd`）**：
  - 给定短周期、长周期、信号周期参数 `(fast, slow, sig)`（标准配置为 `(12, 26, 9)`，但不写死在通用定义里）：定义 `dif = ema_fast - ema_slow`、`dea = ema_sig(dif)`、柱值 `hist = 2 * (dif - dea)`（同时明确无系数 2 版本与系数 2 版本的换算关系，保证核常数 `56 = (9 - 1) * (26 - 12) / 2` 口径一致）。
  - 定义给定时间窗口 `[s, e]` 上的四种精确柱和读数：带号和（signed sum）、红柱和（正部和 `posSum`）、绿柱和（负部绝对值和 `negSum`）、绝对值和（全变差对应 `absSum`），以及离散序列的正变差（`posVar`）、负变差（`negVar`）、全变差（`totalVar`）与端点差（`endpointDiff`）。
- **均线面积代理（`Proxy/MaArea`）**：
  - 给定短周期与长周期两条均线序列，定义窗口 `[s, e]` 上两均线之差的离散面积（带号面积、正部面积、负部面积）以及 `015:42` 定义的趋势平均力度（面积除以窗口时长）。

## M16b 结构冲量族（`Chan/Defs/Dynamics/StructImpulse`）

- **段斜率（离散均速）**：对方向交替区间序列中的每一段，由其端点/值域位移与来源跨度时长定义离散段速度（方向带符号或取模，须明确时间跨度正性条件）。
- **三类端点读数（吸收端点三难定理）**：
  - 围绕单个比较窗口（一系列连续底层段）定义三种结构冲量读数：
    1. `L_in`（纯段内读数：仅依赖窗口内部各段，满足左端点与右端点均在窗口内）；
    2. `L_pre`（带前驱读数：允许依赖窗口起始前一段以保持相邻窗口可加性）；
    3. `L_zero`（从静止起算读数：将窗口起点前的参考速度置零或取中枢尺度基准速度，计算窗口内速度变差或末态速度）。
  - 同时提供端点差读法与正变差读法，**不设主线默认实例**（默认值留待 FM-42 裁定）。

## M16c 三分量力度接口与不变性（`Chan/Defs/Dynamics/Potential`、`Chan/Defs/Dynamics/ForceSpec`）

- **四个显式参数（全部无默认值，`#2322` 硬验收）**：
  1. **窗口（`ForceWindow`）**：由规范分解给出的一对来源跨度（比较前段跨度与比较后段跨度，以及可选锚定中枢区间）；
  2. **势函数（`Potential`）**：定义在时间轴与价格历史上的因果函数族（仅依赖截至时刻 `t` 的前缀，满足 `105:442` 可观察量原则）；包含一次正齐次性、镜像反号性等可检验结构属性（**注意按 `#2322` 评论 1：价格平移不变性不强加在所有势函数上，而挂在读数层**）；
  3. **读法（`ReadingKind`）**：从势函数在窗口上的取值提取标量力度的规则，至少区分端点差（`endpointDiff`）与正变差（`posVar`）；**读数层**声明价格平移不变性、正仿射等变性与多空镜像对称性谓词；
  4. **端点约定（`EndpointConv`）**：区分窗口边界开闭/前驱归属（如 `leftClosed` / `interiorOnly` / `fromRest`），用以刻画三难定理中不同约定的分工。
- **综合力度规范接口（`ForceSpec`）**：组合上述四项无默认值的参数，提供统一标量评估函数 `evalForce`、比较谓词 `forceWeaker`（含严格弱于与不大于两档显式开关），以及正仿射变换下的等变性谓词。

## M17 背驰与区间套（`Chan/Defs/Dynamics/Divergence`）

- **在线背驰谓词 vs 事后确认谓词（B-16，`079:52`）**：
  - **在线谓词 `Div`**：严格只依赖截至当前时刻的历史前缀（进行中的离开段取"起点已确认、终点为当下"的窗口），以显式分解与 `ForceSpec` 为参数；
  - **事后确认谓词 `DivConfirmed`**：在后续历史延拓中确认该位置之后发生了结构回拉/转折且未被继续刷新极值破坏；两者严格分立，不得混用。
- **创新高/新低前提（`061:28`、`[二级旁证 044:234]`）与力度相等开关（`[二级旁证 051:246]`）**：
  - 顶背驰要求后段高点严格高于前段高点（底背驰对称要求严格低于），创新高/新低作为显式独立前提与力度减弱并列；力度比较显式区分严格小于与不大于。
- **趋势背驰与盘整背驰（B-15，`027:14-22`）**：
  - **趋势背驰（`TrendDiv`）**：针对具备至少两个同向分离同级中枢的趋势结构，比较最后一个中枢两侧的连接段（进入段 `b` 与离开段 `c`）；
  - **盘整背驰（`ConsolDiv`）**：针对单个同级中枢，比较同一中枢同侧相邻的两次离开/连接段（如 `a` 与 `c`）。
- **趋势终结三分（B-18，互斥穷尽）**：
  1. 情形一：存在离开最后中枢的 `c` 段且发生趋势背驰（对应 M15 第一类买卖点）；
  2. 情形二：不存在独立 `c` 段，在最后中枢内部盘整背驰后反向离开；
  3. 情形三：最后中枢直接出现反向的第三类买卖点而破坏原趋势。
- **背驰段与区间套（B-20，`027:22`、`027:38-46`、`056:66`）**：
  - 定义某级别的背驰段（`DivSegment`）；
  - 定义纯结构的逐级嵌套区间套（`NestedDivChain`）：一列由大级别到小级别逐级跨度包含的背驰段链，**不强加每一中间级别必须出现同级背驰**（兼容 `056:66` 小转大）。
- **小转大两义分立（B-21，`043:24`、`044:24`）**：
  - 谓词一（`SmallDivTriggersBigTurn`）：小级别背驰引发大级别转折（其必要条件为该大级别最后次级中枢出现反向第三类买卖点）；
  - 谓词二（`TurnWithoutSameLevelDiv`）：无本级别背驰却由次级结构直接完成本级别走势转折。

## M18 无限走势、可观测性与走势必完美拆分（`Chan/Defs/Limits/Liveness`）

- **无限价格路径与前缀投影**：自然数时间轴上的无限序列（配合 `PiNat.cylinder`、`Filter.atTop`、`Filter.EventuallyConst`），以及截断至有限前缀 `n` 的投影操作。
- **可观测性与前缀稳定谓词**：某无限路径性质由有限前缀决定（开集/柱集可判定），以及某在线分析量在 `Filter.atTop` 下最终常值稳定（`EventuallyConst`）。
- **走势必完美的四条独立命名命题签名（B-24，禁用单一未拆分谓词）**：
  1. `DecompExistsSpec`（任一有限历史在合法规则下存在合法分解）；
  2. `CanonicalUniqueSpec`（满足规范性条件的规范分解唯一）；
  3. `BoundedTerminationSpec`（在显式活性假设下，任一未完成中枢/走势类型在有限步内完成或升级）；
  4. `WeakSafetySpec`（弱安全性陈述：买点之后若形成同级中枢，则存在时刻价格不低于买入价，对应 `107:22`）。
- **活性作为命名假设（不设公理）**：显式定义非退化波动活性谓词（排除无限停滞、无限单边无回抽等退化路径）。

## M19a 动力学命名假设与极小市场模型（`Chan/Hypotheses/Dynamics`）

- **五项显式命名假设（全部取值为 `Prop`，零默认值，零 `axiom`，`#2322` 硬验收）**：
  1. `LivenessHyp`（活性假设：走势在任意时刻后不会永久静止，持续产出有限步可达的反向波动或新段）；
  2. `InertiaHyp`（惯性假设：平滑速度/价格增量的二阶变化受显式上界约束）；
  3. `ExhaustionHyp`（衰竭假设：背驰离开段之后可用同向推力存在显式上界或衰减）；
  4. `PullbackHyp`（回复假设：偏离最后中枢区间外部时存在指向中枢区间的显式回复项，注意其定义**严禁直接引用结论谓词"回到中枢"**，满足门禁 14）；
  5. `SymUnimodalBarGroupHyp`（柱组对称单峰假设：吸收 `#2322` 评论 1 订正，精确刻画连续或半计峰值点下柱组单峰对称条件，避免在 `1, 2, 1` 上出现假等式）。
- **极小带参与者标签市场模型（服务第 30 课两前提非内容性定理）**：
  - 定义参与者集合、每时刻各参与者订单/交易事件、成交价格投影，以及第 30 课两条前提的形式化谓词：`EfficientPriceMarket`（价格充分有效）与 `NonIdenticalTrading`（非完全绝对趋同交易，至少存在非同时或异向参与者）。

## M19b 第 33 课中枢回拉研究库模型类签名（`ChanDyn/`，独立库）

注：本包只交付 D1 至 D4 的模型类与假设结构签名（均落在独立目录 `ChanDyn/`，绝不被 `Chan/Defs` 或 `Chan/Final` 导入，满足全部五项红线）。

- **D1 单中枢势阱模型（`ChanDyn/Well.lean`）**：位置序列的二阶离散递推系统，带中枢区间 `[ZD, ZG]`、仅依赖位置的回复力函数、两侧对称性谓词、时间不变性谓词、作用范围有界谓词、滑行期零外力谓词，以及 `b` 段自静止落入条件。
- **D2 推力预算模型（`ChanDyn/Thrust.lean`）**：在 D1 基础上引入外加推力序列、已显示推力预算与比较式预算上界参数（含临界阈值参数位置），用以表述有限期限可达与逃逸边界图（吸收 `#2322` 评论 1 中模型 A 的惯性+回复+有限推力预算骨架）。
- **D3 多中枢叠加场模型（`ChanDyn/Field.lean`）**：将多级中枢集合上的回复力按 `033:24` 叠加成结构场，定义残余推力（二阶差分减结构场）以及最近中枢主导误差比较接口。
- **D4 多参与者向量叠加模型（`ChanDyn/Agents.lean`）**：多组参与者状态向量、异步响应递推与稳定性域接口（吸收 `#2322` 评论 1 中模型 B 的异步响应渐近稳定骨架，明确区分有限期限可达与无限时间稳定）。
